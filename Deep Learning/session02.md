## 1. 넘파이(NumPy)

**NumPy** = 파이썬에서 **큰 숫자 묶음**을 빠르게 다루는 라이브러리입니다.

### 1-1. 고성능 다차원 배열 (`ndarray`)

- **ndarray** = N차원 배열(숫자 상자). 1차원·2차원·3차원 이상을 한 형식으로 둡니다.
- 파이썬 **기본 리스트**보다 **빠르고**, 메모리도 아낍니다.
- **벡터 · 행렬 · 텐서** 같은 수학 구조를 표현하기 쉽습니다.

| 말   | 쉬운 뜻                                | 예          |
| ---- | -------------------------------------- | ----------- |
| 벡터 | 숫자를 **한 줄**로 나열                | `[2, 3]`    |
| 행렬 | 숫자를 **표(행·열)** 로 배열           | 2행 3열 표  |
| 텐서 | 표가 **여러 장** 쌓인 느낌(3차원 이상) | 이미지 배치 |

> **쉽게 이해하기**  
> 장바구니 메모(리스트)로 하나씩 더하면 느립니다.  
> NumPy의 **ndarray**는 “같은 종류 숫자만 넣은 전용 상자”라서, 상자 전체에 `+` · `*`를 한 번에 걸 수 있습니다.  
> 딥러닝의 **텐서**도 결국 이런 숫자 상자의 친척입니다.

### 1-2. 수학·통계 연산

- 합 · 평균 · 분산 · 표준편차 같은 **통계** 함수를 제공합니다.
- **선형대수** 연산도 됩니다. 예: 행렬 곱, 전치(행·열 바꾸기), 역행렬 등.

```python
import numpy as np

a = np.array([1, 2, 3, 4])
print(a.sum())    # 합
print(a.mean())   # 평균
print(a.std())    # 표준편차

M = np.array([[1, 2],
              [3, 4]])
print(M.T)        # 전치: 행과 열 바꾸기
```

> **쉽게 이해하기**  
> `sum` · `mean`은 “표 전체의 합·평균”을 한 줄로 구하는 도구입니다.  
> 나중에 모델이 쓰는 **행렬 곱**도 같은 상자들 위에서 돌아갑니다.

### 1-3. 브로드캐스팅(Broadcasting)

**브로드캐스팅** = 서로 **크기가 다른** 배열끼리도, 규칙에 맞으면 자동으로 맞춰 연산하는 기능입니다.

```python
import numpy as np

x = np.array([[1, 2, 3],
              [4, 5, 6]])   # 2행 3열
b = np.array([10, 20, 30])  # 길이 3
print(x + b)
# [[11 22 33]
#  [14 25 36]]
```

> **쉽게 이해하기**  
> 표의 **모든 행**에 같은 한 줄을 더하고 싶을 때, 손으로 복사하지 않아도 됩니다.  
> NumPy가 “맞게 늘려서” 더해 줍니다. 그게 브로드캐스팅입니다.

### 1-4. 과학·공학 라이브러리의 기반

Pandas · Scikit-Learn · TensorFlow · **PyTorch** 같은 도구들이 **NumPy를 바닥**으로 씁니다.

> **쉽게 이해하기**  
> 딥러닝 도구를 켜기 전에 NumPy를 익히는 이유는,  
> 그 도구들 아래에도 **같은 숫자 상자 생각**이 깔려 있기 때문입니다.  
> Machine Learning [`session03`](../Machine%20Learning/session03.md)에서 더 깊게 만져 볼 수 있습니다.

## 2. 선형대수(linear algebra)

**선형대수** = **벡터와 행렬**을 다루는 수학 분야입니다.

딥러닝에서는 데이터·가중치를 벡터·행렬로 두고, **곱하고 더하며** 예측을 만듭니다.

> **쉽게 이해하기**  
> “점·화살표(벡터)”와 “표를 이용해 화살표를 돌리거나 늘리는 도구(행렬)”를 배우는 과목입니다.  
> 그림 인식·번역 모델도 안에서는 이런 계산이 수없이 돌아갑니다.

### 2-1. 벡터(Vector)

- 숫자를 **일렬로** 나열한 것입니다.
- 좌표 · 데이터 한 줄 · 신호처럼 “순서 있는 숫자 묶음”으로 씁니다.
- 예: `[2, 3]` → 2차원 평면의 **한 점**(또는 원점에서 그 점으로 가는 화살표).

```text
y
|
|     • (2, 3)
|    /
|   /
|  /
| /__________ x
O
```

> **쉽게 이해하기**  
> 벡터는 **주소 메모**와 같습니다.  
> “가로 2, 세로 3”처럼 숫자를 순서대로 적으면, 평면 위 위치를 말할 수 있습니다.  
> 표의 **한 행**(한 사람·한 샘플)도 벡터로 볼 수 있습니다.

### 2-2. 행렬(Matrix)

- 숫자를 **직사각형 표**처럼 배열한 것입니다.
- 벡터를 **변환**하는 도구로 씁니다. 예: 회전 · 확대/축소 · 이동에 가까운 효과.

```text
행렬 A          벡터 x        결과 A·x
[ 2  0 ]       [ 1 ]         [ 2 ]
[ 0  3 ]   ×   [ 1 ]    =    [ 3 ]
(가로 2배, 세로 3배로 늘리는 감각)
```

> **쉽게 이해하기**  
> 행렬은 **요리 레시피 표**에 가깝습니다.  
> 재료(벡터)를 넣으면, 표의 규칙대로 **새 숫자 묶음**이 나옵니다.  
> 신경망의 한 층도 “입력 벡터 × 가중치 행렬 + 편향”으로 이해하면 됩니다.

## 3. 벡터의 내적(inner product)

**내적(inner product)** = 두 벡터가 **같은 길이(차원)** 일 때,  
각 자리 숫자를 **곱한 뒤 전부 더한** 값입니다.  
**점곱(dot product)** 이라고도 부릅니다.

조건: 두 벡터의 **차원(원소 개수)이 같아야** 합니다.

\[
\mathbf{a} \cdot \mathbf{b}
= a_1 b_1 + a_2 b_2 + \cdots + a_n b_n
\]

예:

\[
[1, 2, 3] \cdot [4, 5, 6]
= 1\cdot4 + 2\cdot5 + 3\cdot6
= 4 + 10 + 18
= 32
\]

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(np.dot(a, b))   # 32
print(a @ b)          # 32 (같은 뜻의 다른 표기)
```

| 말          | 쉬운 뜻                                  |
| ----------- | ---------------------------------------- |
| 차원이 같다 | 숫자 개수가 같다 (둘 다 길이 3 등)       |
| 원소별 곱   | 같은 자리끼리 곱한다                     |
| 합          | 그 곱들을 모두 더한다 → **내적 값 하나** |

> **쉽게 이해하기**  
> 내적은 “두 채점표가 **얼마나 비슷하게 높은 점수**를 주는지”를 한 숫자로 요약한 느낌입니다.  
> 같은 자리에서 둘 다 크면 곱이 커지고, 합도 커집니다.  
> 딥러닝·머신러닝에서는 **유사도**, **가중치와 입력을 합치는 한 칸 계산**에 자주 등장합니다.
