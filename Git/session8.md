# Session 8 — VS Code Git GUI & 협업 워크플로우

VS Code의 내장 소스 제어(Source Control) 인터페이스를 사용하여 터미널 명령 없이 GUI로 Git 작업을 수행하는 방법.

---

## 1. GUI 기본 작업 (스테이징 · 커밋 · 취소)

### 저장소 초기화 및 스테이징
1. VS Code에서 작업 폴더 열기
2. 소스 제어 탭 → **Initialize Repository** 클릭
3. 파일 수정 시 소스 제어 아이콘에 변경 파일 개수 표시
4. 파일명 우측 `+` 아이콘 클릭 → 스테이징 (`git add`)
5. 상단 메시지 창에 커밋 메시지 입력 후 **Commit** 버튼 클릭 (`git commit`)

### 변경 사항 비교 및 작업 취소
- **변경 사항 확인**: 파일 클릭 시 나란히 열리는 비교 탭(Diff view)에서 수정 전/후 확인
- **최신 커밋 취소**: 소스 제어 창 메뉴(`...`) → **커밋** → **마지막 커밋 실행 취소 (Undo Last Commit)** (`git reset HEAD^`)
- **스테이징 취소**: 스테이지된 파일 우측 `-` 아이콘 클릭 (`git restore --staged`)
- **파일 수정 내용 폐기**: 변경 사항 파일 우측 `↩` (되돌리기) 아이콘 클릭 (`git restore`)

---

## 2. GUI 브랜치 및 원격 동기화

### 원격 저장소 연결 및 푸시
1. 메뉴(`...`) → **원격** → **원격 추가(Add Remote)** 선택
2. GitHub 저장소 URL 입력 후 원격 이름 지정 (기본값: `origin`)
3. 메뉴(`...`) → **풀, 푸시** → **다음으로 푸시...(Push to...)** 클릭 후 원격 선택

### 브랜치 관리
- **브랜치 생성 및 전환**: 좌측 하단 상태 표시줄의 현재 브랜치명 클릭 → **새 분기 만들기(Create new branch)** 클릭
- **브랜치 병합**: 메뉴(`...`) → **분기(Branch)** → **병합(Merge Branch)** 클릭 후 병합할 브랜치 선택

---

## 3. 팀 협업 실무 워크플로우

### 팀장 역할
1. GitHub 리포지토리 생성
2. 저장소 **Settings → Collaborators**에서 팀원 계정 초대
3. 브랜치 전략 설정 (배포용 브랜치 / 개발용 브랜치 분리)

### 팀원 역할
1. 원격 저장소를 복제(`git clone`)
2. 기능 단위로 새로운 작업 브랜치 생성 및 작업
3. 작업 완료 후 본인의 원격 브랜치로 푸시
4. GitHub에서 **Compare & Pull Request**를 생성하여 리뷰 및 머지 요청
