# Session 9 — README 파일

## 1. README 파일이란?

저장소를 방문하는 사람이 프로젝트를 쉽게 파악할 수 있도록 **저장소의 첫 화면에 노출되는 안내 문서**.

- 프로젝트 소개 및 목적
- 설치 및 실행 방법
- 사용 기술 스택
- 기여 방법 및 라이선스 정보 제공

---

## 2. 생성 및 작성 요령

- **저장소 생성 시**: GitHub에서 새 저장소를 생성할 때 **Add a README file** 옵션을 체크하여 기본 생성
- **기존 저장소에 추가**: 프로젝트 루트 디렉터리에 `README.md` 파일을 생성 후 커밋 및 푸시
- **줄바꿈 규칙**: 일반 마크다운 문법과 동일하게 단순 줄바꿈은 브라우저에서 공백으로 처리될 수 있으므로, 단락 분리를 위해 **줄바꿈을 두 번(Enter x2)** 입력하거나 줄 끝에 공백 2칸을 추가
- **풍부한 콘텐츠 임베드**: 이미지, 배지(Shields.io), 외부 링크, 다이어그램, 테이블 등을 마크다운 문법으로 자유롭게 구성
