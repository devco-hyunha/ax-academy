# 세션 01: 기본 개념

## 1. 기본 개념

### 인공 지능

- 컴퓨터가 사람의 다양한 능력(학습 능력, 추론 능력 등)을 모방하도록 하는 기술
- ⇒ 컴퓨터가 사람처럼 생각하고 동작하게 하도록 사람이 인위적으로 만든 기술

### 머신 러닝

- 데이터를 바탕으로 스스로 학습을 통해 경험을 만들어낸다.
- ⇒ 기계가 학습한다 → 그 경험을 바탕으로 어떤 것을 예측하는 것
- ex) 바둑

### 머신 러닝을 하기 위한 요소

1. 이 모델은 어떤 일을 수행하는가?
2. 학습에 필요한 데이터를 가지고 학습하는가?
3. 학습이 잘 되었는지 평가

- 데이터를 가지고, 알고리즘에게 학습을 시킨다.
- 학습을 시킨 뒤 모의 테스트로 모델 검사 후, 학습 방향을 조정하여 재학습시킨다.
- 반복적인 학습이 다 끝나면 최종 테스트로 모델 성능(수행 능력)을 측정한다.

### 머신 러닝 종류

- **지도학습**: 문제와 정답을 다 알려주고 공부시키는 방법 (오차를 계산해서 데이터 설명)
  - ⇒ 문제를 통해 정답을 예측한다
  - ex) 강아지고양이 분류, 스팸 메일 분류 ⇒ 예측, 분류
- **비지도학습**: 정답을 가르쳐주지 않고 공부시키는 방법 (문제 간 관계성 파악 - 평수가 비슷하네? 화장실 개수 비슷하네?)
  - ⇒ 다양한 데이터를 분석해서 문제 간의 패턴을 분석한다
- **강화학습**: 보상을 통해 상은 최대화, 벌은 최소화하는 방향으로 강화하는 학습 ⇒ 보상

### 용어

- **문제(피쳐, Feature)**: 집에 대한 다양한 데이터(가격에 영향을 미치는 것들) - 지역, 평수, 방 개수 등
- **정답(라벨, Label)**: 모델이 예측해야 하는 값(정답) - 집 가격

## 2. 머신러닝 진행 순서흐름

```
문제 정의 → Data 준비 → Model 선택 → Model 작성 → Model 평가 → Model 개선 → 결과
```

1. Import Libraries
2. Data Load: csv, sklearn, datasets….
3. Data 내용 파악
4. Train / test dataset 분할
5. Feature Scaling / Data 전처리
   - Missing Values 처리 (결측치)
   - Data Formatting (표준화) ex) NY, New York, N.Y 등
   - 편향(skewed data) 처리 (데이터가 골고루 분포되어 있게)
   - Data Normalization (데이터 정규화)
   - Binning (연속된 숫자들의 범위 지정)
   - categorical 변수의 수치화
6. Model object 생성
7. Model train: `fit()`
8. Model 평가 (정확도, 정밀도, 재현율, F1.. 성능 평가)
9. Model 선택 (성능 좋은)
10. Feature Engineering
