# 세션 01: 기본 개념

이 세션은 머신 러닝을 시작하기 전에 꼭 알아야 할 **큰 그림**을 잡습니다. AI·ML이 무엇인지, 어떤 종류가 있는지, Feature/Label이 무엇인지, 그리고 실습할 때 어떤 순서로 진행하는지를 정리합니다.

> **이 세션이 하는 일 (쉬운 말)**  
> 오늘은 코드를 깊게 짜기보다, **지도부터** 그립니다.  
> “컴퓨터가 사람처럼 배운다”는 말이 실제로 무엇을 뜻하는지,  
> 문제를 풀려면 어떤 **재료(데이터)** 와 **정답(라벨)** 이 필요한지,  
> 그리고 노트북에서 모델을 만들 때 **어떤 순서로 손대는지**를 한눈에 익힙니다.

## 1. 기본 개념

### 인공 지능

- 컴퓨터가 사람의 다양한 능력(학습 능력, 추론 능력 등)을 모방하도록 하는 기술
- ⇒ 컴퓨터가 사람처럼 생각하고 동작하게 하도록 사람이 인위적으로 만든 기술

> **쉽게 이해하기**  
> **인공 지능(AI, Artificial Intelligence)** 은 “컴퓨터가 사람처럼 보이게 일하는 기술”의 큰 우산입니다.  
> 사람이 하는 일 중에는 “보고 알아보기”, “말로 답하기”, “규칙을 찾아 판단하기”처럼 머리로 하는 일이 많습니다.  
> AI는 그런 일을 **프로그램으로 흉내 내도록** 만드는 분야라고 생각하면 됩니다.  
> 아직은 “사람 전체”를 통째로 넣는 게 아니라, **특정 능력 하나하나**를 모방하는 쪽에 가깝습니다.

### 머신 러닝

- 데이터를 바탕으로 스스로 학습을 통해 경험을 만들어낸다.
- ⇒ 기계가 학습한다 → 그 경험을 바탕으로 어떤 것을 예측하는 것
- ex) 바둑

> **쉽게 이해하기**  
> **머신 러닝(ML, Machine Learning)** 은 AI 우산 안의 한 갈래입니다.  
> 예전 방식은 “만약 A면 B해라”처럼 **규칙을 사람이 직접** 적었습니다.  
> ML은 반대로, **많은 예시(데이터)** 를 보여주고 컴퓨터가 **규칙/패턴을 스스로 찾게** 합니다.  
>
> 비유: 바둑을 알려줄 때 “이런 모양이면 이렇게 둬라”를 전부 손으로 적기 어렵습니다.  
> 대신 수많은 기보를 보여 주면, 프로그램이 “이런 상황에서는 이런 수가 자주 이겼다”를 **경험처럼** 쌓습니다.  
> 그 경험이 쌓인 결과물이 나중에 “다음 수를 예측”하는 **모델**이 됩니다.

### 머신 러닝을 하기 위한 요소

1. 이 모델은 어떤 일을 수행하는가?
2. 학습에 필요한 데이터를 가지고 학습하는가?
3. 학습이 잘 되었는지 평가

- 데이터를 가지고, 알고리즘에게 학습을 시킨다.
- 학습을 시킨 뒤 모의 테스트로 모델 검사 후, 학습 방향을 조정하여 재학습시킨다.
- 반복적인 학습이 다 끝나면 최종 테스트로 모델 성능(수행 능력)을 측정한다.

> **쉽게 이해하기**  
> ML을 하려면 세 가지를 먼저 분명히 합니다.
>
> 1. **목표**: 이 모델이 무엇을 하게 만들 것인가? (집값 맞추기? 스팸 가리기?)
> 2. **데이터**: 그 일을 배우기에 충분한 예시가 있는가?
> 3. **평가**: “잘 배웠는지”를 숫자로 재는 방법이 있는가?
>
> 실제 흐름은 공부와 비슷합니다.  
> 문제집으로 공부(학습) → 모의고사로 확인(검증) → 틀린 부분 보완 후 다시 공부 →  
> 마지막에 본시험으로 실력 측정(최종 테스트).  
> 한 번에 끝내지 않고 **보고 → 고치고 → 다시 학습**을 반복합니다.

### 머신 러닝 종류

- **지도학습**: 문제와 정답을 다 알려주고 공부시키는 방법 (오차를 계산해서 데이터 설명)
  - ⇒ 문제를 통해 정답을 예측한다
  - ex) 강아지고양이 분류, 스팸 메일 분류 ⇒ 예측, 분류
- **비지도학습**: 정답을 가르쳐주지 않고 공부시키는 방법 (문제 간 관계성 파악 - 평수가 비슷하네? 화장실 개수 비슷하네?)
  - ⇒ 다양한 데이터를 분석해서 문제 간의 패턴을 분석한다
- **강화학습**: 보상을 통해 상은 최대화, 벌은 최소화하는 방향으로 강화하는 학습 ⇒ 보상

> **쉽게 이해하기**  
> 배우는 방식이 세 갈래로 나뉩니다.
>
> - **지도학습(Supervised Learning)**  
>   문제와 **정답(Label)** 을 같이 줍니다.  
>   예: “이 사진은 고양이”, “이 메일은 스팸”.  
>   학생이 답지 있는 문제집으로 공부하는 것과 같습니다.  
>   예측이 틀리면 “얼마나 틀렸는지(오차)”를 보고 고칩니다.
>
> - **비지도학습(Unsupervised Learning)**  
>   정답은 안 주고, **비슷한 것끼리 묶거나 패턴**만 찾게 합니다.  
>   예: 집 데이터에서 “평수·화장실 수가 비슷한 집끼리” 무리 짓기.  
>   답지 없이 “이 문제들 사이 공통점이 뭐지?”를 찾는 공부입니다.
>
> - **강화학습(Reinforcement Learning)**  
>   행동할 때마다 **상(+)** 또는 **벌(-)** 을 받으며,  
>   상을 많이·벌을 적게 받는 쪽으로 행동을 강화합니다.  
>   게임에서 점수를 올리는 법을 스스로 익히는 것과 비슷합니다.

### 용어

- **문제(피쳐, Feature)**: 집에 대한 다양한 데이터(가격에 영향을 미치는 것들) - 지역, 평수, 방 개수 등
- **정답(라벨, Label)**: 모델이 예측해야 하는 값(정답) - 집 가격

> **쉽게 이해하기**  
> - **Feature(피처/특성)** = 모델에 넣는 **힌트·원인 정보**.  
>   집값 예시면 지역, 평수, 방 개수처럼 “가격에 영향 줄 법한 것”들입니다.  
>   시험으로 치면 **문제지에 적힌 조건**입니다.
>
> - **Label(라벨/정답)** = 모델이 **맞춰야 하는 값**.  
>   같은 예에서 집 가격입니다.  
>   시험으로 치면 **답란의 정답**입니다.
>
> 지도학습은 “Feature로 Label을 맞추는 법”을 데이터로부터 배우는 일입니다.

## 2. 머신러닝 진행 순서흐름

```
문제 정의 → Data 준비 → Model 선택 → Model 작성 → Model 평가 → Model 개선 → 결과
```

1. Import Libraries — 라이브러리 불러오기
2. Data Load — 데이터 불러오기: csv, sklearn, datasets….
3. Data 내용 파악 — 데이터 살펴보기
4. Train / test dataset 분할 — 학습용·테스트용 데이터 나누기
5. Feature Scaling / Data 전처리 — 특성 스케일링·데이터 전처리
   - Missing Values 처리 (결측치)
   - Data Formatting (표준화) ex) NY, New York, N.Y 등
   - 편향(skewed data) 처리 (데이터가 골고루 분포되어 있게)
   - Data Normalization (데이터 정규화)
   - Binning (연속된 숫자들의 범위 지정)
   - categorical 변수의 수치화
6. Model object 생성 — 모델 객체 만들기
7. Model train: `fit()` — 모델 학습
8. Model 평가 (정확도, 정밀도, 재현율, F1.. 성능 평가) — 성능 재기
9. Model 선택 (성능 좋은) — 더 좋은 모델 고르기
10. Feature Engineering — 특성 엔지니어링(특성을 더 잘 만들기)

> **쉽게 이해하기**  
> 위 목록은 실습에서 **거의 매번 반복하는 레시피**입니다.  
> 요리로 비유하면 이렇습니다.
>
> 1. **도구 꺼내기** (`Import Libraries`): 칼·냄비처럼 `numpy`, `pandas` 등을 준비
> 2. **재료 꺼내기** (`Data Load`): CSV 파일이나 연습용 데이터셋 읽기
> 3. **재료 살펴보기**: 몇 줄인지, 이상한 값이 있는지 눈으로 확인
> 4. **연습용/시험용 나누기** (`Train` / `Test`):  
>    전부로 공부하면 “외우기”가 되므로, 일부는 **안 보고** 남겨 실력 확인에 씀
> 5. **손질하기** (전처리):  
>    빈칸(결측치) 채우기, 표기 통일(NY / New York),  
>    숫자 크기 맞추기(정규화), 글자 범주를 숫자로 바꾸기 등
> 6~7. **요리하기**: 모델 만들고 `fit()`으로 학습
> 8~9. **맛보기·고르기**: 정확도 등으로 평가하고, 더 나은 쪽을 선택
> 10. **레시피 다듬기** (`Feature Engineering`):  
>     특성을 합치거나 새로 만들어 예측이 더 잘되게 손보기
>
> 처음엔 순서를 **외우지 않아도** 됩니다.  
> “불러오고 → 살펴보고 → 나누고 → 손질하고 → 학습하고 → 평가한다”만 기억해도 충분합니다.
