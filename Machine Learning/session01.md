# 세션 01: 기본 개념

이 세션은 머신 러닝을 시작하기 전에 꼭 알아야 할 **큰 그림**을 잡습니다. AI·ML이 무엇인지, 어떤 종류가 있는지, Feature/Label이 무엇인지, 그리고 실습할 때 어떤 순서로 진행하는지를 정리합니다.

> **이 세션이 하는 일 (쉬운 말)**  
> 오늘은 코드를 깊게 짜기보다, **지도부터** 그립니다.  
> “컴퓨터가 사람처럼 배운다”는 말이 실제로 무엇을 뜻하는지,  
> 문제를 풀려면 어떤 **재료(데이터)** 와 **정답(라벨)** 이 필요한지,  
> 그리고 노트북에서 모델을 만들 때 **어떤 순서로 손대는지**를 한눈에 익힙니다.

## 1. 기본 개념

### 인공 지능

- 컴퓨터가 사람의 다양한 능력(학습 능력, 추론 능력 등)을 모방하도록 하는 기술
- ⇒ 컴퓨터가 사람처럼 생각하고 동작하게 하도록 사람이 인위적으로 만든 기술

> **쉽게 이해하기**  
> **인공 지능(AI, Artificial Intelligence)** 은 컴퓨터가 사람처럼 보이게 일하게 만드는 기술의 큰 범주입니다.  
> 보기·판단·대화처럼 머리로 하는 일을 프로그램으로 옮길 때 쓰는 말입니다.  
> 지금은 사람 전체를 한 번에 만드는 것이 아니라, 필요한 능력을 하나씩 따로 만드는 쪽에 가깝습니다.

### 머신 러닝

- 데이터를 바탕으로 스스로 학습을 통해 경험을 만들어낸다.
- ⇒ 기계가 학습한다 → 그 경험을 바탕으로 어떤 것을 예측하는 것
- ex) 바둑

> **쉽게 이해하기**  
> **머신 러닝(ML, Machine Learning)** 은 예시를 많이 보여 주면 컴퓨터가 규칙을 스스로 찾는 방법입니다.  
> 예전에는 사람이 “만약 A면 B”처럼 규칙을 직접 적었습니다.  
> ML은 **데이터(많은 사례)** 로 그 과정을 대신합니다. 바둑 기보를 잔뜩 보여 주는 것과 같습니다.  
> 그렇게 만든 결과물이 다음을 맞추는 **모델**입니다.

### 머신 러닝을 하기 위한 요소

1. 이 모델은 어떤 일을 수행하는가?
2. 학습에 필요한 데이터를 가지고 학습하는가?
3. 학습이 잘 되었는지 평가

- 데이터를 가지고, 알고리즘에게 학습을 시킨다.
- 학습을 시킨 뒤 모의 테스트로 모델 검사 후, 학습 방향을 조정하여 재학습시킨다.
- 반복적인 학습이 다 끝나면 최종 테스트로 모델 성능(수행 능력)을 측정한다.

> **쉽게 이해하기**  
> ML을 시작하기 전에 세 가지를 정합니다.  
> 1. **목표**: 모델이 무엇을 할지(집값, 스팸 여부 등)  
> 2. **데이터**: 배울 예시가 충분한지  
> 3. **평가**: 잘 배웠는지 숫자로 재는 방법  
> 학습 → 검증 → 보완 → 최종 테스트 순으로 돌리면, 외운 것인지 실력인지 구분하기 쉽습니다.

### 머신 러닝 종류

- **지도학습**: 문제와 정답을 다 알려주고 공부시키는 방법 (오차를 계산해서 데이터 설명)
  - ⇒ 문제를 통해 정답을 예측한다
  - ex) 강아지고양이 분류, 스팸 메일 분류 ⇒ 예측, 분류
- **비지도학습**: 정답을 가르쳐주지 않고 공부시키는 방법 (문제 간 관계성 파악 - 평수가 비슷하네? 화장실 개수 비슷하네?)
  - ⇒ 다양한 데이터를 분석해서 문제 간의 패턴을 분석한다
- **강화학습**: 보상을 통해 상은 최대화, 벌은 최소화하는 방향으로 강화하는 학습 ⇒ 보상

> **쉽게 이해하기**  
> 학습 방식은 크게 세 가지입니다.  
> - **지도학습(Supervised Learning)**: 문제와 **라벨(label, 정답)** 을 같이 줍니다. 틀린 만큼 **오차**로 고칩니다.  
> - **비지도학습(Unsupervised Learning)**: 정답 없이 비슷한 것끼리 묶거나 패턴만 찾습니다.  
> - **강화학습(Reinforcement Learning)**: 행동할 때 **보상·벌**로 좋은 행동을 늘립니다.  
> 분류·스팸 거르기는 보통 지도학습에 해당합니다.

### 용어

- **문제(피쳐, Feature)**: 집에 대한 다양한 데이터(가격에 영향을 미치는 것들) - 지역, 평수, 방 개수 등
- **정답(라벨, Label)**: 모델이 예측해야 하는 값(정답) - 집 가격

> **쉽게 이해하기**  
> - **피처(feature, 특성)** 는 모델에 넣는 힌트입니다. 집값 예에서는 지역·평수·방 개수입니다.  
> - **라벨(label, 정답)** 은 맞춰야 하는 값입니다. 같은 예에서는 집 가격입니다.  
> 지도학습은 피처로 라벨을 맞추는 법을 데이터에서 배웁니다.

## 2. 머신러닝 진행 순서흐름

```
문제 정의 → Data 준비 → Model 선택 → Model 작성 → Model 평가 → Model 개선 → 결과
```

1. Import Libraries — 라이브러리 불러오기
2. Data Load — 데이터 불러오기: csv, sklearn, datasets….
3. Data 내용 파악 — 데이터 살펴보기
4. Train / test dataset 분할 — 학습용·테스트용 데이터 나누기
5. Feature Scaling / Data 전처리 — 특성 스케일링·데이터 전처리
   - Missing Values 처리 (결측치)
   - Data Formatting (표준화) ex) NY, New York, N.Y 등
   - 편향(skewed data) 처리 (데이터가 골고루 분포되어 있게)
   - Data Normalization (데이터 정규화)
   - Binning (연속된 숫자들의 범위 지정)
   - categorical 변수의 수치화
6. Model object 생성 — 모델 객체 만들기
7. Model train: `fit()` — 모델 학습
8. Model 평가 (정확도, 정밀도, 재현율, F1.. 성능 평가) — 성능 재기
9. Model 선택 (성능 좋은) — 더 좋은 모델 고르기
10. Feature Engineering — 특성 엔지니어링(특성을 더 잘 만들기)

> **쉽게 이해하기**  
> 실습에서는 같은 순서를 거의 매번 반복합니다.  
> 도구 불러오기 → 데이터 읽기·확인 → 학습용·시험용 나누기 → 전처리 → `fit()`으로 학습 → 점수로 평가 → 필요하면 특성 손보기.  
> 처음엔 전부 외울 필요는 없고, “불러오고, 살펴보고, 나누고, 손질하고, 학습하고, 평가한다”만 기억해도 됩니다.

3. 지도학습과 비지도학습의 가장 큰 차이는 무엇인가요?
4. Train / Test로 데이터를 나누는 이유는 무엇인가요?
5. 머신러닝 진행 순서에서 “전처리”가 왜 필요할까요?

<details>
<summary>답 보기</summary>

1. AI는 큰 우산이고, 머신 러닝은 그 안에서 “데이터로 스스로 패턴을 배우는” 방법이다.
2. Feature = 지역·평수·방 수처럼 힌트. Label = 맞출 집 가격(정답).
3. 지도학습은 정답(Label)을 주고 배우고, 비지도학습은 정답 없이 패턴·묶음만 찾는다.
4. 공부한 문제만 잘하면 “외운 것”일 수 있어서, 안 본 데이터로 실력을 확인하기 위함이다.
5. 빈칸·표기 불일치·스케일 차이 등이 있으면 모델이 잘못 배우기 쉬워, 재료를 먼저 손질해야 한다.
