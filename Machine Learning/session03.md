## 1. ndarray란?

- **ndarray (N-dimensional array)**: NumPy의 핵심 데이터 구조는 다차원 배열 객체
- 파이썬 기본 리스트보다 훨씬 빠르고 효율적
- 특징:
  - 모든 원소가 같은 타입 (ex: 전부 int, 전부 float)
  - 메모리에 연속적으로 저장 → 연산 속도 빠름
  - 벡터화 연산 지원 (반복문 없이도 배열 전체에 연산 가능)
- numpy array: 1차원 = vector, 2차원 = matrix, 3차원 이상 = tensor
- rank = array의 dimension (차원), shape = 각 dimension의 size

```python
import numpy as np

arr = np.array([1, 2, 3, 4])   # 1차원 배열
print(arr)                     # [1 2 3 4]
print(arr.dtype)               # int64
print(arr.shape)               # (4,) → 원소 4개짜리 1차원

arr = np.array([[1, 2, 3], [4, 5, 6]])
print(arr[0, 1])     # 2  (0행 1열)
print(arr[:, 2])     # [3 6] (모든 행, 2열)
print(arr[1, :])     # [4 5 6] (1행 전체)

arr = np.array([1, 2, 3, 4, 5])
print(arr.mean())   # 평균 → 3.0
print(arr.std())    # 표준편차
print(arr.sum())    # 합
print(arr.max())    # 최댓값
```

> **쉽게 이해하기**  
> **NumPy** = “숫자 계산 전용 도구 상자”.  
> 핵심 상자 이름은 **ndarray**(N-dimensional array, N차원 배열)입니다.
>
> 파이썬 **리스트**는 만능 가방에 가깝습니다. 숫자·글자·다른 리스트를 섞을 수 있지만,  
> 큰 숫자 뭉치를 한꺼번에 더하고 곱할 때는 느립니다.
>
> ndarray는 규칙이 더 빡셉니다.
>
> - 보통 **같은 종류**의 숫자만 넣음 (전부 int, 전부 float)
> - 메모리를 **줄줄이 붙여** 둠 → CPU가 빠르게 훑을 수 있음
> - **벡터화**: `for` 문 없이 `arr * 2`처럼 배열 전체에 연산을 한 번에 적용
>
> 차원 감각:
>
> - 1차원 → **vector(벡터)**: 한 줄 숫자 `[1, 2, 3]`
> - 2차원 → **matrix(행렬)**: 표처럼 행·열
> - 3차원 이상 → **tensor(텐서)**: 표가 여러 장 쌓인 느낌
>
> **shape** = 각 축의 길이. `(4,)`는 길이 4인 1차원, `(2, 3)`은 2행 3열입니다.  
> **rank** = 차원이 몇 개인지(축이 몇 개인지).
>
> 인덱싱 예: `arr[0, 1]` = 0번째 행, 1번째 열.  
> `:` 는 “전부”라는 뜻. `arr[:, 2]` = 모든 행의 2번 열.

## 2. Transpose (행·열 전치)

- transpose는 행과 열의 위치를 바꾸는 연산이다.
- 수학적으로 `Aᵀ`는 원소 (i, j)를 (j, i)로 옮기는 연산이며, `ndarray.T`와 같은 의미다.

```python
import numpy as np

arr = np.array([[1, 2, 3],
               [4, 5, 6]])           # 2행 3열
print(arr.T)
# [[1 4]
#  [2 5]
#  [3 6]]                           # 3행 2열

print(arr.T.shape)                   # (3, 2) → shape가 (2, 3)에서 (3, 2)로 바뀜
print(arr.T[0, 1])                   # 4 → arr[1, 0]과 같은 위치
```

- 1차원 배열은 transpose해도 내용이 변하지 않는다. 벡터는 축이 하나뿐이라 전치해도 shape는 `(n,)` 그대로다.
- ML에서 특징(features)은 열, 표본은 행으로 배치하는 형태가 흔하다.

> **쉽게 이해하기**  
> **Transpose(전치)** = 표의 **가로·세로를 뒤집기**.  
> 2행 3열 표를 세우면 3행 2열이 됩니다.  
> 코드에서는 `arr.T` 또는 `arr.transpose()`입니다.
>
> 비유: 엑셀에서 행에 쓰던 이름을 열로 옮기는 것과 비슷합니다.  
> 숫자 자체는 그대로인데, **자리(행↔열)** 만 바뀝니다.
>
> ML에서 왜 자주 나오나?  
> 보통 **한 행 = 한 사람(표본)**, **한 열 = 한 특징(Feature)** 으로 표를 만듭니다.  
> 어떤 공식은 “특징끼리 곱”이 필요해서, 잠깐 방향을 바꿔야 합니다. 그때 `T`를 씁니다.
>
> 참고: 진짜 1차원 `(n,)` 벡터는 축이 하나라서, 전치해도 모양이 거의 안 바뀝니다.

## 3. transpose가 필요한 연산과 형태

- **내적·외적 연산에서 transpose가 연산 방향을 맞춰준다.** `X.T @ X`는 표본·특징 행렬을 축 순서에 따라 정리하는 대표 형태다.

```python
X = np.array([[1, 2, 3],
              [4, 5, 6]])           # 2행(표본) × 3열(특징)
Z = X.T @ X                         # (3×2) @ (2×3) → 특징 축 기준 (3, 3) 정리
print(Z)
# [[17 22 27]
#  [22 29 36]
#  [27 36 45]]
```

- 선형 회귀 `(X.T @ X)` 역을 구하는 공식도 대표적으로 transpose가 축 정렬을 담당한다.

> **쉽게 이해하기**  
> `@` 는 행렬 곱입니다.  
> 곱하려면 **앞 행렬의 열 개수**와 **뒤 행렬의 행 개수**가 같아야 합니다.
>
> `X`가 (표본 × 특징) = `(2, 3)`이면,  
> `X.T`는 `(3, 2)`가 되어 `X.T @ X` → `(3, 3)`이 됩니다.  
> 결과의 한 칸은 “특징끼리의 관계(얼마나 같이 움직이는지)” 느낌이 납니다.
>
> 선형 회귀 공식에서도 `X.T @ X` 형태가 자주 나옵니다.  
> “왜 뒤집지?”보다 **축을 맞춰서 곱할 수 있게 만든다**고 기억하면 됩니다.

## 4. 다차원 transpose

- 3차원 tensor는 축 순서 `0, 1, 2`가 `2, 1, 0`으로 뒤집혀 `shape`가 거꾸로 바뀐다.
- 축 순서를 직접 지정하면 특정 축끼리만 전치할 수 있다.

```python
x = np.arange(24).reshape(2, 3, 4)  # 축 = (0, 1, 2)
print(x.T.shape)                     # (4, 3, 2) → 전체 축 순서 = (2, 1, 0)
print(x.transpose(0, 2, 1).shape)    # (2, 4, 3) → 축 순서 = (0, 2, 1)
```

> **쉽게 이해하기**  
> 3차원은 “표가 여러 장”이라고 생각하면 됩니다.  
> 축 번호 `0, 1, 2`는 각각 “몇 번째 장 / 행 / 열” 같은 역할입니다.
>
> - `x.T` → 축 순서를 통째로 뒤집음 `(0,1,2)` → `(2,1,0)`
> - `x.transpose(0, 2, 1)` → “0번은 그대로, 1번과 2번만 바꿔”
>
> 처음엔 shape 숫자만 보고 “축 순서가 바뀌었구나” 정도만 이해해도 충분합니다.

---

## 5. transpose가 계산 속도가 빠른 이유

- `.T`는 배열을 복사하지 않고 축 순서만 바꾸는 view 연산이다.

> **쉽게 이해하기**  
> 숫자를 메모리에서 통째로 복사해 새 표를 만들지 않고,  
> “읽는 순서(축)만 다르게 보라”는 **view(뷰)** 를 만듭니다.  
> 그래서 큰 배열에서도 전치 자체는 가벼운 편입니다.  
> (나중에 값을 바꾸면 원본과 연결될 수 있으니, “같은 데이터를 다른 창으로 본다”고 생각하면 됩니다.)

## 6. `range()` vs `numpy.arange()`

| 구분      | range()               | numpy.arange()       |
| --------- | --------------------- | -------------------- |
| 소속      | 파이썬 내장 함수      | NumPy 라이브러리     |
| 반환 타입 | range 객체 (이터러블) | NumPy 배열 (ndarray) |
| 지원 타입 | 정수만 가능           | 정수 + 실수 가능     |
| 활용 분야 | 반복문, 인덱싱        | 수치계산, 배열 연산  |

> **쉽게 이해하기**  
> 둘 다 “숫자 나열을 만든다”는 점은 비슷합니다.
>
> - `range(5)` → `for` 문에 쓰기 좋은 **파이썬 기본** 도구. 보통 정수만.
> - `np.arange(0, 1, 0.1)` → **NumPy 배열**을 바로 만듦. 실수 간격도 가능.
>
> “반복만 할 거면 `range`, 배열 계산할 거면 `arange`”로 고르면 됩니다.

## 7. 난수 생성

- `np.random.seed()`: 난수를 생성할 때 사용하는 시작점(seed)을 고정
  - → 실행할 때마다 똑같은 난수 배열이 나온다. (재현 가능성 확보)
- `np.random.randn(5, 4)`: 표준 정규분포 (N(0, 1))에서 난수 생성
  - 평균(μ) = 0, 표준편차(σ) = 1
  - (5, 4) → 5행 4열짜리 2차원 배열

> **쉽게 이해하기**  
> **난수** = 무작위에 가까운 숫자. 연습용 데이터나 초기값을 만들 때 자주 씁니다.
>
> - `seed`를 고정하면: 같은 코드를 다시 돌려도 **같은 난수**가 나옵니다.  
>   친구와 결과를 맞추거나, 버그를 재현할 때 필수입니다.  
>   비유: 주사위 굴리기 전에 **같은 시작 눈**을 맞추는 것.
>
> - `randn(5, 4)`: “평균 0, 표준편차 1”인 종 모양(정규분포)에서  
>   5행 4열짜리 숫자를 뽑습니다. ML 예제에서 “가짜 데이터”로 자주 등장합니다.
