# 세션 05: Matplotlib

- 파이썬에서 2D 데이터 시각화 라이브러리
- 막대그래프, 선그래프, 히스토그램, 산점도, 파이차트 등 거의 모든 기본 그래프 지원

> **이 세션이 하는 일 (쉬운 말)**  
> 숫자만 잔뜩 적힌 표는 읽기 어렵습니다.  
> **Matplotlib**은 그 숫자를 **그림(그래프)** 으로 바꿔 주는 파이썬 도구입니다.  
> 오늘은 “어떤 상황에 어떤 그래프를 쓰는지”와,  
> 가장 자주 쓰는 그리기 코드(`plot`, `scatter`, `bar`, `hist`)를 익힙니다.

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

plt.plot(x, y)          # 선 그래프
plt.title("Line Plot")  # 그래프 제목
plt.xlabel("X-axis")    # x축 이름
plt.ylabel("Y-axis")    # y축 이름
plt.show()
```

> **쉽게 이해하기**  
> `import matplotlib.pyplot as plt` = “그림 그리는 도구를 `plt`라는 짧은 이름으로 불러온다”.  
> 자주 쓰는 순서:
>
> 1. `plt.plot(...)` 등으로 **무엇을 그릴지** 정한다
> 2. `title` / `xlabel` / `ylabel`로 **제목·축 이름**을 붙인다
> 3. `plt.show()`로 **화면에 보여 준다**
>
> 비유: 종이에 점을 찍고(`plot`), 제목을 쓰고(`title`), 친구에게 보여 주는 것(`show`).

---

## 주요 그래프 종류

### (1) 선 그래프 (Line Plot)

```python
plt.plot([1, 2, 3], [1, 4, 9], marker='o', color='red', linestyle='--')
plt.title("Line Graph")
plt.show()
```

> **쉽게 이해하기**  
> **선 그래프(Line Plot)** = 점이 시간에 따라, 또는 순서대로 **어떻게 변하는지** 볼 때 씁니다.  
> 예: 날짜별 기온, 주차별 매출, 에포크마다 줄어드는 손실(loss).
>
> - `marker='o'`: 각 지점에 동그라미 표시
> - `color='red'`: 선 색깔
> - `linestyle='--'`: 점선
>
> **언제 쓰나:** “어제→오늘→내일처럼 **흐름·추세**”가 중요할 때.  
> 카테고리 비교(A반 vs B반)에는 보통 막대 그래프가 더 잘 맞습니다.

---

### (2) 산점도 (Scatter Plot)

```python
x = [5, 7, 8, 7, 6, 9]
y = [99, 86, 87, 88, 100, 86]
plt.scatter(x, y, color='green')
plt.title("Scatter Plot")
plt.show()
```

> **쉽게 이해하기**  
> **산점도(Scatter Plot)** = 점 하나씩을 **흩뿌려** 두 숫자 사이의 관계를 볼 때 씁니다.  
> 예: 키(x)와 몸무게(y), 공부 시간과 점수.
>
> 선으로 이으면 “순서”가 있는 것처럼 보이지만,  
> 산점도는 “이 사람과 저 사람은 **서로 다른 관측**”이라서 **점으로만** 둡니다.
>
> **언제 쓰나:** “이 두 값이 **같이 커지나?** / 뭉쳐 있나?”를 눈으로 확인할 때.  
> 머신러닝에서는 feature와 정답의 관계를 먼저 훑어볼 때도 자주 씁니다.

---

### (3) 막대 그래프 (Bar Chart)

```python
x = ["A", "B", "C"]
y = [3, 7, 5]
plt.bar(x, y, color='blue')
plt.title("Bar Chart")
plt.show()
```

> **쉽게 이해하기**  
> **막대 그래프(Bar Chart)** = **이름(카테고리)** 끼리 크기를 비교할 때 씁니다.  
> 예: 반별 점수 평균, 요일별 방문자 수, 객실 등급별 생존자 수.
>
> x축은 보통 문자 라벨(`"A"`, `"B"`, `"C"`),  
> y축은 그 그룹의 숫자(합계·개수·평균)입니다.
>
> **언제 쓰나:** “누가 더 큰가?”를 **한눈에 비교**할 때.  
> 연속된 흐름(시간 변화)을 보려면 선 그래프가 더 자연스럽습니다.

---

### (4) 히스토그램 (Histogram)

```python
import numpy as np

data = np.random.randn(1000)  # 정규분포 랜덤 데이터
plt.hist(data, bins=30, color='purple')
plt.title("Histogram")
plt.show()
```

> **쉽게 이해하기**  
> **히스토그램(Histogram)** = 숫자 데이터가 **어디에 얼마나 몰려 있는지** 보는 그래프입니다.  
> 예: 시험 점수 분포, 나이 분포, 요금(Fare) 분포.
>
> 비유: 키 측정 결과를 “150~160”, “160~170”처럼 **구간(bin)** 에 나눠 넣고,  
> 각 구간에 몇 명인지 **막대 높이**로 보여 줍니다.
>
> - `bins=30`: 구간을 30개로 나눔 (많을수록 더 잘게 자름)
> - `np.random.randn(1000)`: 정규분포에 가까운 난수 1000개 (연습용)
>
> **막대 그래프와 차이:**  
> 막대 = **이미 정해진 카테고리** 비교.  
> 히스토그램 = **연속 숫자를 구간으로 잘라** 분포를 봄.
>
> **언제 쓰나:** “대부분 어디에 몰려 있고, 이상치(튀는 값)가 있나?”를 볼 때.

---

## 그래프 고르기 한눈에

```text
흐름·추세(시간/순서)     → 선 그래프 (Line)
두 숫자의 관계·흩어짐    → 산점도 (Scatter)
카테고리끼리 크기 비교   → 막대 그래프 (Bar)
숫자 값의 분포·몰림      → 히스토그램 (Histogram)
```
