# 세션 18: 다이아몬드 회귀 — Feature와 이상치

이번 세션은 **diamonds** 데이터로 회귀를 준비할 때 꼭 보는 두 가지를 정리합니다.  
(1) Feature·타겟이 무엇인지, (2) **이상치(Outlier)** 를 어떻게 찾고 다루는지입니다.

> **이 세션이 하는 일 (쉬운 말)**  
> 다이아몬드 **가격(price)** 을 맞추기 전에, 어떤 **힌트 칸(Feature)** 이 있는지 봅니다.  
> 값이 **너무 튀는 점(이상치)** 이 있는지도 봅니다.  
> **IQR**, **Z-Score**, **Boxplot** 으로 튀는 값을 찾는 법을 배웁니다. (뜻은 아래에서 하나씩 설명합니다)  
> 오늘은 모델보다 **데이터를 깨끗이 보는 눈**이 목표입니다.

---

## 1. diamonds Feature와 타겟

| Feature | 의미 (한 줄) |
| ------- | ------------ |
| **carat** | 무게(캐럿). 클수록 대체로 비쌈 |
| **cut** | 컷 품질 (범주형) |
| **color** | 색 등급 (범주형) |
| **clarity** | 투명·내포물 등급 (범주형) |
| **depth** | 깊이 비율 |
| **table** | 테이블(윗면) 비율 |
| **x / y / z** | 길이·너비·깊이 (mm) |
| **price** | **타겟** — 맞출 가격 |

- 회귀의 목표는 **price**를 예측하는 것입니다.
- cut·color·clarity는 문자(범주)라, 모델에 넣기 전 인코딩이 필요할 수 있습니다.

### clarity 등급 (한 줄 요약)

**FL → IF → VVS1 → VVS2 → VS1 → VS2 → SI1 → SI2 → I1 → I2 → I3**  
(앞에서 뒤로 갈수록 내포물이 많아져 **투명도가 낮아지는** 쪽)

> **쉽게 이해하기**  
> **Feature** = 문제를 푸는 **힌트 칸**.  
> **타겟(price)** = 맞춰야 할 **답**.  
> carat·크기·등급이 힌트이고, 가격이 답입니다.

## 2. 이상치란 / 왜 확인하는지

- **이상치(Outlier)**: 다른 점들과 비해 **유난히 크거나 작은** 값
- 측정 오류·특수 케이스·진짜 극단값이 섞여 있을 수 있습니다.
- 회귀·평균·일부 모델은 튀는 점에 **크게 흔들릴** 수 있어,  
  먼저 눈으로·규칙으로 확인합니다. (무조건 삭제가 답은 아님)

> **쉽게 이해하기**  
> **이상치** = 다른 값들과 너무 동떨어진 숫자입니다.  
> 반 평균 키를 낼 때 한 명만 3m로 적혀 있으면 평균이 이상해집니다.  
> 그 3m가 오타인지, 진짜 특수 사례인지 확인합니다.

---

## 3. IQR (사분위 범위) — Tukey 방식

- **Q1**: 하위 25% 지점, **Q3**: 상위 75% 지점
- **IQR** = Q3 − Q1 (가운데 50%의 폭)
- **하한** = Q1 − 1.5 × IQR  
- **상한** = Q3 + 1.5 × IQR  
- 하한보다 작거나 상한보다 큰 값을 이상치 후보로 봅니다.
- **왜 1.5인가?**  
  Tukey가 제안한 **관례적 배수**로, 너무 빡세지도·느슨하지도 않은 기본값입니다.  
  (데이터가 정규분포에 가깝다면 대략 양쪽 끝의 극단을 걸러 내는 정도로 쓰입니다.)

> **쉽게 이해하기**  
> **Q1** = 아래에서 25% 지점. **Q3** = 아래에서 75% 지점.  
> **IQR** = Q3 − Q1 (가운데 절반의 폭).  
> 그 폭의 **1.5배** 밖을 “너무 튄 값”으로 보는 규칙입니다.  
> 1.5는 자주 쓰는 기본값입니다.

---

## 4. Z-Score

- **Z-Score** = (x − 평균) / 표준편차
- “평균에서 표준편차 몇 칸 떨어졌는지”를 나타냅니다.
- 흔히 |Z|가 3을 넘으면 이상치 후보로 봅니다. (정규분포 가정이 강할 때)

> **쉽게 이해하기**  
> **Z-Score** = (값 − 평균) ÷ 표준편차.  
> **표준편차** = 값들이 평균에서 얼마나 흩어졌는지.  
> 0에 가까우면 평범, ±3 근처면 **꽤 드문 쪽**입니다.

---

## 5. Boxplot 읽는 법

| 요소 | 의미 |
| ---- | ---- |
| **Box** | Q1~Q3 (가운데 50%) |
| **Median** | 상자 안 중앙선 (중앙값) |
| **Whiskers** | 상자 밖으로 뻗은 수염 (보통 IQR 규칙 안쪽 끝) |
| **Outlier** | 수염 밖 점으로 찍힌 이상치 후보 |

> **쉽게 이해하기**  
> **Boxplot** = 숫자를 **상자 그림**으로 요약한 것.  
> 상자 = Q1~Q3(가운데 절반).  
> 수염(Whiskers) = 아직 괜찮은 범위.  
> 점 = 한번 더 볼 **튀는 값**.
