## 2. 시그모이드와 임계값 (0.5 기본)

- 시그모이드: 아무 숫자를 **0~1 사이 확률**로 눌러 줌
- 기본 임계값 **0.5**: 확률 ≥ 0.5 → 1, 아니면 0
- 임계값을 바꾸면 \"산다\"고 말하는 횟수가 바뀜  
  - 낮춤 → 보통 재현율↑, 정밀도↓  
  - 높임 → 보통 정밀도↑, 재현율↓

> **쉽게 이해하기**  
> 확률 = 살 것 같은 정도.  
> 임계값 = “이 정도면 샀다”는 **합격선**.  
> 낮추면 더 많이 산다고 하고, 높이면 까다롭게 가릅니다.

---

## 3. StandardScaler — 학습 표에만 fit

나이와 연봉은 단위가 다릅니다. `StandardScaler`로 맞춤니다.

1. 학습(`X_train`)에만 `fit` (+ `transform`)
2. 테스트(`X_test`)는 `transform`만

> **쉽게 이해하기**  
> fit = 학습 표의 평균·표준편차를 **기억**.  
> transform = 그 기억으로 숫자 변환.  
> 테스트에는 fit을 다시 하지 않습니다.

---

## 4. 점수 — accuracy / precision / recall / f1

| 지표 | 쉬운 말 | 한 줄 |
| ---- | ------- | ----- |
| **accuracy** | 전체 중 맞힌 비율 | 전반적인 맞춤 |
| **precision** | \"산다\"고 한 것 중 진짜 산 비율 | 거짓 알람이 적은지 |
| **recall** | 진짜 산 사람 중 찾아낸 비율 | 놓친 구매자가 적은지 |
| **f1** | 정밀도·재현율의 조화평균 | 둘을 한 숫자로 |

노트북에서는 임계값 0.3 / 0.6을 바꿔 가며 같은 점수를 비교합니다.

> **쉽게 이해하기**  
> **F1** = 정밀도와 재현율을 한 점수로 묶은 값. 둘 다 잘해야 올라갑니다.

---

## 5. predict_proba

- `predict` → 임계값(기본 0.5)을 거친 **0/1**
- `predict_proba` → 각 클래스 확률 `[안 살 확률, 살 확률]`
- 구매 확률만 쓰려면 `y_proba[:, 1]`

> **쉽게 이해하기**  
> predict = 예/아니오.  
> predict_proba = 각 답의 **확률**. 임계값을 직접 쓰려면 이게 필요합니다.

---

## 6. 혼동행렬

`confusion_matrix(..., labels=[1, 0])` 일 때:

```
[TP  FN]
[FP  TN]
```

히트맵으로 숫자를 보면 어디에 틀렸는지 한눈에 보입니다.

> **쉽게 이해하기**  
> **혼동행렬** = 맞힌 것·틀린 것을 표로 센 것.  
> **TP** = 샀다 맞고 샀다고 함. **FN** = 샀는데 안 샀다고 함.  
> **FP** = 안 샀는데 샀다고 함. **TN** = 안 샀다 맞고 안 샀다고 함.
