오늘은 그 무리가 **얼마나 잘 묶였는지** 보는 **실루엣 계수**를 정리합니다.

> **이 세션이 하는 일 (쉬운 말)**  
> 클러스터 결과가 “잘 모이고, 다른 무리와 잘 떨어져 있는지”를 **-1 ~ 1** 점수에 가깝게 요약합니다.  
> 1에 가까우면 좋고, 0 근처면 애매하고, 음수면 잘못된 무리에 들어간 느낌이 큽니다.

---

## 1. 실루엣 계수란

**실루엣 계수(Silhouette Coefficient)** = 군집이 잘 됐는지 보는 지표.

각 점마다 두 가지를 같이 봅니다.

| 말         | 쉬운 뜻                                                      |
| ---------- | ------------------------------------------------------------ |
| **응집도** | 자기 무리 안에서 다른 점들과 **얼마나 가까운지** (잘 어울림) |
| **분리도** | **다른 무리**와 **얼마나 먼지** (잘 갈라짐)                  |

점 `i`에 대해 흔히 쓰는 기호:

| 기호     | 뜻                                                                       |
| -------- | ------------------------------------------------------------------------ |
| **a(i)** | 같은 클러스터 안 다른 점들과의 평균 거리 (작을수록 자기 무리에 잘 붙음)  |
| **b(i)** | 가장 가까운 **다른** 클러스터 점들과의 평균 거리 (클수록 옆 무리와 멀음) |

실루엣 값의 느낌:

```text
s(i) ≈ ( b(i) - a(i) ) / max( a(i), b(i) )
```

| 식의 조각           | 쉬운 뜻                                                                                                     |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| **s(i)**            | 점 `i` 하나의 실루엣 점수                                                                                   |
| **b(i) − a(i)**     | “옆 무리와 먼 정도”에서 “내 무리와 가까운 정도”를 뺀 값. **클수록** 내 무리에 잘 들어가고 옆과 잘 갈라진 편 |
| **max(a(i), b(i))** | 두 거리 중 **더 큰 쪽**. 이걸로 나눠 **-1 ~ 1** 근처 비율로 맞춤                                            |
| **전체 나눗셈**     | 차이만 보면 숫자 크기가 제각각이라, max로 나눠 **같은 척도**로 비교                                         |

> **쉽게 이해하기**  
> 분자 `(b − a)`는 “옆과 얼마나 멀고, 나와 얼마나 가까운지”의 **차이**입니다.  
> 분모 `max(a, b)`는 그 차이를 **비율**로 만들어, 점마다 공정하게 비교하게 합니다.  
> 그래서 `a`가 작고 `b`가 크면 점수는 **1에 가깝고**, 둘이 비슷하면 **0 근처**, `a`가 더 크면 **음수**가 됩니다.  
> 점마다 `s(i)`를 구한 뒤, 보통 **평균**을 모델 점수로 씁니다.

---

## 2. 숫자를 어떻게 읽나

| 값             | 해석                                                        |
| -------------- | ----------------------------------------------------------- |
| **1에 가까움** | 잘 클러스터링됨 — 자기 무리에 잘 들어가고, 다른 무리와 멀다 |
| **0 근처**     | 경계 — 어느 무리인지 애매하다                               |
| **음수**       | 잘못된 편 — 다른 클러스터에 있는 편이 나을 수 있다          |

전체 모델 점수는 보통 점별 실루엣의 **평균**으로 봅니다.

> **쉽게 이해하기**  
> **실루엣 점수**가 1에 가까우면 무리가 잘 모였다고 보면 됩니다.  
> 각 점마다 “내 무리 안에서는 가깝고, 옆 무리와는 먼지”를 재어 전체 평균을 냅니다.  
> 학급마다 붙어 있기 점수를 매긴 뒤 평균 내는 것과 비슷합니다.

---

## 3. 왜 max로 나누나

수업 예시:

- `a(i) = 200`
- `b(i) = 300`
- 차이만 보면 `300 - 200 = 100` → **단위·크기가 제각각**이라 해석이 어렵다

**max(a, b)** 로 나누면 값이 대략 **-1 ~ 1** 구간에 들어와, 서로 다른 점을 같은 척도로 비교할 수 있습니다.

> **쉽게 이해하기**  
> 원시 차이만 보면 거리 단위마다 숫자 크기가 달라 비교하기 어렵습니다.  
> **max**로 나누면 대략 **마이너스 1에서 1** 사이 비율로 맞춰 점마다 같은 기준으로 비교할 수 있습니다.

## 4. DBSCAN 점 종류 (같은 Notion 메모)

session22의 **밀도 기반(DBSCAN)** 과 이어지는 용어입니다.

| 말               | 쉬운 뜻                                                              |
| ---------------- | -------------------------------------------------------------------- |
| **epsilon (ε)**  | “이웃”으로 볼 **반경**                                               |
| **minPts**       | 그 반경 안에 있어야 하는 **최소 점 개수**                            |
| **core point**   | 반경 안 점이 minPts **이상** → 무리의 **중심이 될 수 있는 점**       |
| **border point** | 스스로는 minPts 미달이지만, 어떤 core의 무리에는 들어감 → **경계점** |

예 (수업): `minPts = 4`

- 점 P 주변(ε 안)에 점 5개(자신 포함) → **core point**, 한 군집으로 본다
- 점 P2 주변이 3개뿐 → core는 못 되지만, P 무리에 속하면 **border point**
- 점 P3 주변이 4개 → `minPts=4`를 만족하므로 역시 **core point**

> **쉽게 이해하기**  
> **core**(코어) 점은 반경 안에 이웃이 충분히 많아 무리의 중심 역할을 할 수 있는 점입니다.  
> **border**(보더) 점은 이웃은 적지만, 이미 생긴 무리 가장자리에 붙어 있는 점입니다.
