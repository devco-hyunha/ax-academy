## 1. 차원의 저주

**차원의 저주(Curse of Dimensionality)** = 칸(차원)이 늘수록 생기는 어려움.

| 현상             | 쉬운 뜻                                                     |
| ---------------- | ----------------------------------------------------------- |
| 빈 공간 증가     | 칸이 늘면 공간이 커지는데, 데이터가 적으면 **빈 칸이 많음** |
| 성능 하락        | 변수(칸)가 늘수록 모델이 잘 맞추기 **어려워질 수 있음**     |
| 데이터 희소성    | 고차원에서는 점들이 **멀리 흩어짐**                         |
| 거리 왜곡        | 점 사이 거리가 비슷해져 **K-Means** 같은 거리 기반이 약해짐 |
| 필요 데이터 폭증 | 같은 밀도를 유지하려면 **훨씬 많은 표본**이 필요            |

대응: **차원을 줄이거나**, **데이터를 더 모읍니다**.

> **쉽게 이해하기**  
> 칸이 2개면 종이에 점을 찍듯 **평면**으로 볼 수 있습니다.  
> 칸이 수십 개면 공간이 너무 넓어져, 같은 고객 수로는 점이 **드문드문** 보입니다.  
> “가까운 이웃”을 고르거나 군집을 나누는 일이 흐려집니다.  
> 비유하면, 방이 커지는데 가구(데이터)는 그대로라 **빈 복도만 늘어난** 느낌입니다.  
> 해결은 방을 줄이거나(차원 축소), 가구를 더 들이는 것(데이터 추가)입니다.

## 2. PCA (주성분 분석)

**PCA(Principal Component Analysis)** = 주성분 분석.

- 데이터의 **분산**(퍼짐)을 최대한 지키면서
- 서로 **직교**(직각)인 **새 축**을 찾고
- 고차원 표본을 **낮은 차원**으로 옮깁니다.

목표는 **정보 손실을 줄이면서** 칸을 줄이는 것입니다.  
줄인 뒤에는 시각화·분석·학습이 더 수월해질 수 있습니다.

| 말             | 쉬운 뜻                                     |
| -------------- | ------------------------------------------- |
| **주성분(PC)** | 새로 만든 축. PC1이 가장 넓게 퍼진 방향     |
| **PC1**        | 정보가 가장 많은(분산이 큰) 첫 축           |
| **PC2**        | PC1과 직각이면서, 그다음으로 정보가 많은 축 |

흐름 (수업 Notion 기준):

1. 데이터가 **많이 퍼진 방향**을 찾는다
2. 그 방향으로 **새 축(PC1)** 을 잡는다
3. 불필요한 칸을 줄이고 **중요한 축만** 남긴다

> **쉽게 이해하기**  
> 칸이 많은 표를, “정보가 많이 담긴 **새 줄자**” 몇 개로 다시 그리는 일입니다.  
> 원본 칸을 그냥 버리지 않고 **섞어서 새 축**을 만듭니다.  
> PC1은 “점들이 가장 넓게 퍼진 방향”, PC2는 그와 **직각**이면서 그다음으로 퍼진 방향입니다.  
> 칸 수는 줄어도, 퍼짐(정보)은 되도록 남기려는 것이 목표입니다.  
> 자세한 손코딩은 session30에서 이어갑니다.
