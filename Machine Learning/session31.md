## 2. 노트북 흐름

| 순서 | 내용                                                     |
| ---- | -------------------------------------------------------- |
| 1    | `../data/train.csv` 읽기                                 |
| 2    | `Age`·`Cabin`·`Embarked` 결측 개수                       |
| 3    | `Age` → 평균으로 채움 / `Embarked` → 최빈값(`mode()[0]`) |
| 4    | 조건 선택: `Pclass==1` & `Age>30`                        |
| 5    | `AgeGroup` 만들기 (`Adult` / `Child`)                    |
| 6    | `Pclass`별 Age·Fare 평균, Survived 합                    |
| 7    | `Cabin`에 `B42` 있는지 · Fare 상위 5 · Age 상위 5        |
| 8    | `Age>=30` & `Fare>=100` 행 고르기                        |
| 9    | `pd.cut`으로 Fare 4구간                                  |
| 10   | 숫자 칸 상관 · seaborn 히트맵                            |

데이터 경로:

```python
df = pd.read_csv("../data/train.csv")
```

> **쉽게 이해하기**  
> 2~3. **결측**은 빈칸입니다. 나이는 **평균**으로, 탑승항은 **가장 흔한 값**으로 메웁니다.  
> 4·8. “1등석이면서 30살 초과”처럼 **조건으로 줄만 골라** 봅니다.  
> 5~6. 나이를 어른/아이로 나누고, 등급별로 **평균·합**을 내어 무리 차이를 봅니다.  
> 7. 특정 객실이 있는지, 요금·나이 **상위 몇 명**을 확인합니다.  
> 9. `pd.cut`은 요금을 **구간 상자**로 나누는 도구입니다.  
> 10. **상관**은 두 숫자가 같이 오르내리는 정도입니다. 히트맵은 그 정도를 **색**으로 보여 줍니다.
