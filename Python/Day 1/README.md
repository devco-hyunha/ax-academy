## 1. 파이썬 주요 자료형 요약 (Quick Reference)

| 자료형 (Type) | 키워드    | 설명                                                  | 예시                           |
| :------------ | :-------- | :---------------------------------------------------- | :----------------------------- |
| **정수**      | `int`     | 양수, 음수, 0을 포함하는 정수 (메모리 허용 시 무제한) | `3`, `-5`, `0`                 |
| **실수**      | `float`   | 소수점을 포함하는 숫자                                | `10.4`, `3.14`, `3.`, `.5`     |
| **복소수**    | `complex` | 실수부와 허수부(`j`)로 구성된 수                      | `1 + 2j`, `complex(3)`         |
| **불리언**    | `bool`    | 참(`True`) 또는 거짓(`False`) 논리값                  | `True`, `False`                |
| **문자열**    | `str`     | 따옴표(`" "` 또는 `' '`)로 감싼 문자열                | `"Python"`                     |
| **리스트**    | `list`    | 순서가 있고 수정 가능한 데이터 집합 (대괄호 `[]`)     | `["Python", 1, 2]`             |
| **튜플**      | `tuple`   | 순서가 있으나 수정 불가능한 불변 시퀀스 (소괄호 `()`) | `(4, 2, 4)`                    |
| **집합**      | `set`     | 중복을 허용하지 않고 순서가 없는 집합 (중괄호 `{}`)   | `{1, 23, 4}`                   |
| **딕셔너리**  | `dict`    | 키-값(`Key: Value`) 쌍으로 매핑된 데이터 집합         | `{"name": "gildong", "id": 3}` |

## 2. Day 1 핵심 복습 포인트 (Cheat Sheet)

1. **"파이썬의 모든 것은 객체다"**:
   - 모든 변수는 단순 메모리 주소가 아닌 클래스로 정의된 객체 인스턴스이며, 내장 속성과 메서드를 가집니다.
2. **소수점 버림 vs 반올림**:
   - `int(3.8)` 형 변환은 **버림(3)** 처리됩니다.
   - 포매팅 `%.4f`는 지정 자리 다음에서 **반올림** 처리됩니다.
3. **슬라이싱 핵심 규칙**:
   - `[start:stop:step]`에서 `stop` 인덱스는 **미포함**입니다.
   - `[::-1]`은 문자열을 뒤집는 가장 대표적인 파이썬 관용구입니다.
4. **C 스타일 포매팅 `%` 규칙**:
   - 2개 이상의 값을 전달할 때는 반드시 `%(값1, 값2)` 튜플 형태로 묶어야 합니다.
5. **포매팅 3대 방식 선택 기준**:
   - 현대 파이썬에서는 가독성과 속도가 가장 뛰어난 **f-string (`f'{var}'`)** 사용이 표준 권장사항입니다.
   - 키워드 매핑이나 템플릿 재사용이 필요할 때는 `str.format()`을 활용합니다.
