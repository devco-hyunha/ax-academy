## 1. 실습 코드 및 단계별 해설

### 1.1 데이터 타입 선언

```python
str1 = "Python"
bool1 = True
float1 = 10.4
int1 = 3
list1 = [str1]
dict1 = { "name": "gildong", "id": 3 }
tuple1 = (4, 2, 4)
set1 = {1, 23, 4}
```

- **설명**:
  - 파이썬의 대표 자료형들을 각각 변수에 할당합니다.
  - `list1 = [str1]`: 기존 변수 `str1`을 원소로 포함하는 리스트를 생성합니다.
  - `dict1`: `Key: Value` 쌍으로 구성된 딕셔너리입니다.
  - `tuple1`: `()` 소괄호로 선언하며, 한 번 생성되면 원소의 추가/수정/삭제가 불가능한 불변(Immutable) 시퀀스입니다.
  - `set1`: `{}` 중괄호로 선언하며, 중복을 허용하지 않고 순서가 없는 집합형입니다.

### 1.2 `type()` 함수를 통한 타입 확인 및 객체 개념

```python
print(type(str1)) # <class 'str'>
print(type(bool1)) # <class 'bool'>
print(type(float1)) # <class 'float'>
print(type(int1)) # <class 'int'>
print(type(list1)) # <class 'list'>
print(type(dict1)) # <class 'dict'>
print(type(tuple1)) # <class 'tuple'>
print(type(set1)) # <class 'set'>

# str1 = "Python"
# str1이라는 문자자체를 객체로 만들고 다양한 속성(변수), 행동(함수)을 넣을 수 있다
```

- **설명**:
  - `type(변수)`는 해당 데이터가 어떤 클래스(`class`)로 정의된 인스턴스(객체)인지 출력합니다.
  - **"파이썬의 모든 것은 객체(Object)다"**:
    - 변수 `str1 = "Python"`을 선언하면 단순 텍스트가 아닌 `str` 클래스의 객체가 메모리에 생성됩니다.
    - 객체는 고유한 값(상태)뿐 아니라 속성(변수)과 다양한 내장 행동(메서드/함수)을 함께 가집니다.

### 1.3 정수 연산 및 무제한 정수 (Arbitrary-Precision)

```python
# 숫자형 연산자
# +, -, *, /, %
i1 = 30
i2 = 944
big_int1 = 123456789012345678901234567890
big_int2 = 999999999999999999999999999999999999
print(i1 + i2)
print(big_int1 + big_int2) # 메모리 허용 범위 내에서는 무한대 연산 가능(정수 크기 제한 없음)

print(3**4) # 3의 4제곱
```

- **설명**:
  - `i1 + i2`: 일반적인 사칙연산(`+`, `-`, `*`, `/`, `%`)을 수행합니다.
  - **무제한 정수(Arbitrary-precision integers)**:
    - C나 Java와 달리 파이썬 3의 `int`는 32비트/64비트 고정 한계로 인한 오버플로(Overflow)가 없습니다.
    - 시스템 메모리가 허용하는 한 수십~수천 자리 이상의 거대한 정수도 손실 없이 정확히 계산합니다.
  - `3 ** 4`: 거듭제곱 연산자로 $3^4 = 81$을 계산합니다.

### 1.4 실수 연산

```python
f1 = 1.234
f2 = 3.458
print(f1 + f2)
print(f1 - f2)
print(f1 * f2)
print(f1 / f2)
```

- **설명**:
  - 실수형(`float`) 간의 사칙연산 결과도 실수형으로 반환됩니다.
  - **주의**: 컴퓨터의 부동소수점 표현 방식 특성상 미세한 연산 오차(IEEE 754 표준)가 발생할 수 있습니다.

### 1.5 자료형 변환 (Type Casting)

```python
# 형 변환
a = 3.
b = 10
c = .5
d = 12.5
print(type(a), type(b), type(c), type(d))

# 정수 → 실수
print(float(b))

# 실수 c → 정수
print(int(c))

# bool true → 정수
print(int(True))

print(float(True))
print(int(False))
print(complex(3))
```

- **설명**:
  - `3.` $\rightarrow$ `3.0` (`float`), `.5` $\rightarrow$ `0.5` (`float`): 앞/뒤 숫자가 0일 때 생략 가능한 파이썬의 축약 실수 표기법입니다.
  - `float(b)`: 정수 `10`을 실수 `10.0`으로 변환합니다.
  - `int(c)`: 실수 `.5`를 정수 `0`으로 변환합니다 (**반올림이 아니라 소수점 이하를 버림(Truncation)**).
  - `int(True)` / `float(True)`: 불리언 `True`는 숫자 `1` / `1.0`으로 변환됩니다.
  - `int(False)`: 불리언 `False`는 숫자 `0`으로 변환됩니다.
  - `complex(3)`: 정수 `3`을 복소수 `(3+0j)`로 변환합니다.

### 1.6 복소수(`complex`) 자료형 심화

```python
# 복소수 예시
c1 = 1 + 2j
print(c1.real)        # 1.0 (실수부)
print(c1.imag)        # 2.0 (허수부)
print(c1.conjugate()) # (1-2j) (켤레복소수)
print(abs(c1))        # 약 2.236 (절댓값/크기)
```

- **설명**:
  - 수학에서는 허수단위로 $i$를 쓰지만 파이썬 및 공학계열에서는 **`j` 또는 `J`**를 사용합니다.
  - 숫자 뒤에 공백 없이 바로 붙여야 합니다 (`2j`는 허수, `2 * j`는 변수 `j`와의 곱셈).
  - 전기전자공학, 신호 처리(푸리에 변환), 물리 시뮬레이션 및 `NumPy` 수치해석 등에서 활용됩니다.

---

### 1.7 내장 수치 함수 (Built-in Numeric Functions)

```python
# 수치 함수
print(abs(-4)) # 절대값
print(pow(3, 4)) # 3의 4제곱
print(divmod(7, 3)) # 7을 3으로 나눈 몫과 나머지
```

- **설명**:
  - `abs(-4)`: 절댓값 `4`를 반환합니다.
  - `pow(3, 4)`: 거듭제곱을 계산하여 `81`을 반환합니다 (`3 ** 4`와 동일).
  - `divmod(7, 3)`: 몫(`7 // 3 = 2`)과 나머지(`7 % 3 = 1`)를 한 번에 계산하여 튜플 `(2, 1)`로 반환합니다. 시간/분 환산이나 페이징 처리 시 유용합니다.
