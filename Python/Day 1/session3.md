## 1. 실습 코드 및 단계별 해설

### 1.1 문자열 인덱싱 및 슬라이싱 상세 (양수/음수 인덱스, 스텝, 역순)

```python
str1 = "Python interesting"
print('str1[7]:', str1[7])
print('str1[0:3]:', str1[0:3]) # 0~2 까지 출력
print('str1[4:]:', str1[4:]) # 4~끝까지 출력
print('str1[1:4]:', str1[1:4]) # 1~3 까지 출력
print('str1[:3]:', str1[:3]) # 0~2 까지 출력
print('str1[1:]:', str1[1:]) # 1~끝까지 출력
print('str1[:]:', str1[:]) # 0~끝까지 출력
print('str1[:len(str1)]:', str1[:len(str1)]) # 문자열 전체를 출력
print('str1[1:-2]:', str1[1:-2]) # 1~끝-2 까지 출력
print('str1[-4:-2]:', str1[-4:-2]) # 끝-4~끝-2 까지 출력
print('str1[1:4:2]:', str1[1:4:2]) # 1~3 까지 2의 배수 인덱스 출력
print('str1[::2]:', str1[::2]) # 0 부터 2의 배수 인덱스 출력
print('str1[::-1]:', str1[::-1]) # 문자열 전체를 역순으로 출력
```

- **설명**:
  - 대상 문자열: `"Python interesting"` (길이: 18)
  - **인덱싱**: `str1[7]` $\rightarrow$ 7번 인덱스의 문자 `'i'` 추출.
  - **슬라이싱 기본 문법**: `str1[시작:끝:증감폭]` (단, **끝 인덱스는 미포함**).
    - `str1[0:3]`, `str1[:3]`: 0부터 2까지 `'Pyt'`.
    - `str1[1:4]`: 1부터 3까지 `'yth'`.
    - `str1[4:]`: 4번 인덱스부터 끝까지 `'on interesting'`.
    - `str1[:]`, `str1[:len(str1)]`: 문자열 전체 복사 및 출력.
  - **음수 인덱스(Negative Index)**:
    - 뒤에서부터 셀 때 `-1`이 마지막 글자입니다.
    - `str1[1:-2]`: 1번 인덱스부터 뒤에서 3번째 글자까지 추출.
    - `str1[-4:-2]`: 뒤에서 4번째부터 뒤에서 3번째 글자까지 추출.
  - **스텝(증감폭, Step) 슬라이싱**:
    - `str1[1:4:2]`: 인덱스 1부터 3까지 중 2칸 간격(1번) 문자 추출.
    - `str1[::2]`: 전체에서 2칸 간격(짝수 인덱스: 0, 2, 4...) 문자 추출.
    - `str1[::-1]`: **증감폭이 `-1`이므로 전체 문자열을 역순(Reverse)으로 뒤집어 반환**합니다.

### 1.2 슬라이싱 실습 예제: 주민등록번호 분리

```python
# test case 1: 주민번호 나누기
pin = "881120-1068234"
yyyymmdd = pin[:6]
num = pin[7:]
print('yyyymmdd:', yyyymmdd)
print('num:', num)

# test case 2: 주민번호 성별 나누기
pin = "881120-1068234"
gender = pin[7]
print('gender:', gender)
```

- **설명**:
  - `pin[:6]`: 앞자리 생년월일 6자리(`"881120"`)를 슬라이싱으로 추출합니다.
  - `pin[7:]`: 하이픈(`-`, 6번 인덱스) 다음인 7번 인덱스부터 끝까지 뒷자리(`"1068234"`)를 추출합니다.
  - `pin[7]`: 성별 식별값인 7번 인덱스의 단일 문자(`"1"`)를 인덱싱으로 추출합니다.

### 1.3 C 스타일 문자열 포매팅 (`%` 연산자) 기본

```python
# format = c스타일(%s:문자열, %d:정수, %f:실수, %c: character, %e: 과학적 표기법)
# - %s에서 s는 string(문자열)의 약자
# - %d에서 d는 decimal(정수)의 약자
# - %f에서 f는 float(실수)의 약자
# - %c에서 c는 character(문자)의 약자
# - %e에서 e는 exponential(과학적 표기법)의 약자
print('문자열 %s와 문자열 %s가 있다' %('one', 'two'))
print('정수 %d와 정수 %d가 있다' %(3, 4))
print('실수 %f가 있다' %(3.14)) # %f는 기본 소수점 6자리까지 출력
```

- **설명**:
  - 문자열 내부의 서식 지정자(`%s`, `%d`, `%f` 등) 위치에 뒤이어 오는 `% (값1, 값2, ...)`의 값을 순서대로 대입합니다.
  - **주요 서식 지정자**:
    - `%s`: 문자열 (String)
    - `%d`: 정수 (Decimal)
    - `%f`: 부동소수점 실수 (Float) - 기본적으로 소수점 아래 6자리까지 출력 (`3.140000`)
    - `%c`: 문자 1개 (Character)
    - `%e`: 과학적 표기법 (Exponential)
  - 대입할 값이 2개 이상일 때는 반드시 괄호 `%(값1, 값2)` 형태의 튜플로 전달해야 합니다.

### 1.4 포매팅 정렬 및 자리수 제어

```python
# %10s는 10자리 문자열을 출력
# %[숫자][type]는 숫자만큼 %[type]을 출력, 오른쪽 정렬
# %[-숫자][type]는 숫자만큼 %[type]을 출력, 왼쪽 정렬

print('%10s' %('hi')) # 오른쪽 정렬
print('%-10s' %('hi')) # 왼쪽 정렬

# test case 3: 정수 4, 6을 입력 → %d 로 출력
print('정수 %d, %d를 출력' %(4, 6))

# test case 4: python 이라는 문자를 20자리에서 오른쪽 정렬로 출력
print('%20s' %('python'))
```

- **설명**:
  - **오른쪽 정렬 (`%[숫자]s`)**:
    - `%10s`: 전체 공간 10칸을 확보하고 문자열을 오른쪽에 배치한 뒤 앞쪽은 공백으로 채웁니다 (`'        hi'`).
  - **왼쪽 정렬 (`%[-숫자]s`)**:
    - `%-10s`: 전체 공간 10칸을 확보하고 문자열을 왼쪽에 배치한 뒤 뒤쪽을 공백으로 채웁니다 (`'hi        '`).
  - `%20s`: 20칸을 확보하여 `"python"`을 오른쪽 정렬로 출력합니다.

### 1.5 소수점 자릿수 표현 제어

```python
# 소수점 표현
print('%0.4f' %(3.141592653589793)) # 소수점 4자리까지 출력
print('%10.4f' %(3.141592653589793)) # 최소 정수 10자리에 소수점 4자리까지 출력
print('%10.4f' %(1234567890123.141592653589793)) # 최소 정수 10자리에 소수점 4자리까지 출력
```

- **설명**:
  - **`%0.4f`**: 소수점 아래 4자리까지만 출력하도록 지정합니다 (`3.1416`, 마지막 자리는 반올림 처리됨).
  - **`%10.4f`**:
    - 소수점 아래는 4자리로 고정하고, 전체 출력 길이를 최소 10칸(공백 포함) 확보하여 오른쪽 정렬합니다.
    - 정수부가 이미 10자리를 넘는 큰 숫자(`1234567890123.141592...`)의 경우, 자릿수가 잘리지 않고 전체 숫자가 정상 출력됩니다 (최소 자릿수 보장 개념).

## 2. 핵심 요약

1. **소수점 버림 vs 반올림**:
   - `int()` 형 변환은 소수점을 **버림(Truncation)**합니다.
   - 포매팅(`%.4f`)은 지정된 자릿수 다음 자리에서 **반올림**하여 표시합니다.
2. **슬라이싱의 끝 번호 미포함**:
   - `[start:stop]`에서 `stop` 인덱스는 포함되지 않으므로, 6번 인덱스 앞까지 자르려면 `[:6]`으로 지정해야 합니다.
3. **음수 인덱싱의 기준**:
   - 끝에서 첫 번째 문자는 `-1`, 뒤에서 두 번째 문자는 `-2`입니다.
4. **문자열 뒤집기**:
   - `[::-1]`은 문자열을 역순으로 뒤집는 파이썬 고유의 가장 간결하고 효율적인 방법입니다.
5. **C 스타일 포매팅 `%` 사용 시 튜플 괄호**:
   - 포맷팅할 인자가 2개 이상일 때 괄호(`%(a, b)`)를 생략하면 문법 오류(`TypeError`)가 발생하므로 반드시 튜플로 묶어야 합니다.
