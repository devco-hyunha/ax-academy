## 1. 실습 코드 및 단계별 해설

### 1.1 `str.format()` 기본 사용법 및 인덱스 활용

```python
# format 함수
print('I eat {0} apples'.format(3))

print('{} {}'.format('one', 'two'))
print('{1} {0}'.format('one', 'two')) # 인덱스 1과 0을 사용하여 출력
```

- **설명**:
  - `{}`(중괄호 플레이스홀더)를 두고 `.format()` 인자로 값을 전달하면 순서대로 대입됩니다.
  - `{0}`, `{1}`처럼 **인덱스 번호**를 지정하면 전달받은 인자의 순서를 바꾸거나 동일한 값을 여러 번 재사용할 수 있습니다.
  - `{1} {0}`은 1번째 인자인 `'two'`를 먼저 출력하고, 0번째 인자인 `'one'`을 뒤에 출력하여 `'two one'`이 됩니다.

### 1.2 자릿수 패딩, 0 채우기 및 소수점 표현

```python
print('{0:06d}'.format(15)) # 6자리 빈 문자열에 15를 채움, 0으로 채움
print('{0:06d}'.format(-15)) # 6자리 빈 문자열에 -15를 채움, 0으로 채움

print('{0:f}'.format(3.14)) # 3.14를 소수점 6자리까지 출력
print('{0:10f}'.format(3.14)) # 10자리 빈 문자열에 3.14를 소수점 6자리까지 출력
print('{0:10.4f}'.format(3.14)) # 10자리 빈 문자열에 3.14를 소수점 4자리까지 출력
print('{0:10.4f}'.format(3.14)) # 10자리 빈 문자열에 3.14를 소수점 4자리까지 출력
```

- **설명**:
  - **`{0:06d}`**: 총 6자리 공간을 확보하고, 빈 공간을 `0`으로 채워 정수를 출력합니다.
    - `15` $\rightarrow$ `000015`
    - `-15` $\rightarrow$ `-00015` (부호 기호 `-` 포함 6자리)
  - **`{0:f}`**: 실수를 기본 소수점 6자리까지 출력합니다 (`3.140000`).
  - **`{0:10.4f}`**: 전체 10칸(공백 포함)을 확보하고 소수점 아래는 4자리까지 출력합니다 (`    3.1400`).

### 1.3 f-string(포맷 스트링) vs `format()` 비교

```python
# 문자열 포멧팅
name = '홍길동'
age = 30

str1 = f'저는 {name}입니다. 나이는 {age}살입니다.'
print(str1)

str2 = '저는 {0}입니다. 나이는 {1}살입니다.'.format(name, age)
print(str2)
```

- **설명**:
  - **f-string (파이썬 3.6+ 도입)**:
    - 문자열 앞에 `f` 또는 `F` 접두사를 붙이고, 중괄호 안에 직접 변수명이나 표현식(`x + y`)을 넣는 최신 문법입니다.
    - 가독성이 가장 뛰어나며, `.format()`이나 `%` 방식보다 **실행 속도가 빠르고 직관적**이어서 현대 파이썬 개발에서 가장 권장되는 표준 방식입니다.

### 1.4 서식 스타일 비교 (C 스타일 `%` vs 이름 지정 `format()`)

```python
x = 10
y = 30
z = 'Lee'

# c스타일(서식문자)
test1 = 'z=%s, sum=%d' % (z, (x + y))
print(test1)

# format() 이름(키워드) 지정 방식
test2 = 'z={z}, sum={sum}'.format(z = z, sum = (x + y))
print(test2)
```

- **설명**:
  - `%` 서식 문자는 타입을 엄격하게 맞춰야 하고 인자 개수가 많아지면 가독성이 떨어집니다.
  - `.format(key=value)`처럼 **이름(키워드 인자)**을 지정하면 파라미터가 많아져도 순서에 구애받지 않고 명확하게 대입할 수 있습니다.

### 1.5 문자열 및 숫자 정렬과 공백 채우기 (format vs f-string)

```python
# format() 방식 정렬
print('{0:<10}'.format('hi')) # 10자리 공간에서 왼쪽 정렬
print('{0:>10}'.format('hi')) # 10자리 공간에서 오른쪽 정렬
print('{0:^10}'.format('hi')) # 10자리 공간에서 중앙 정렬
print('{0:*^10}'.format('hi')) # 10자리 공간에서 중앙 정렬 후 남는 공간을 '*'로 채움

# f-string 방식 정렬
print(f'{"hi":<10}') # 왼쪽 정렬
print(f'{"hi":>10}') # 오른쪽 정렬
print(f'{"hi":^10}') # 중앙 정렬
print(f'{"hi":*^10}') # 중앙 정렬 후 남는 공간을 '*'로 채움

# 숫자 변수 f-string 서식 제어
n = 50
print(f'{n:^10}') # 10칸 중앙 정렬 ('    50    ')
print(f'{n:_<20}') # 20칸 왼쪽 정렬 후 빈칸을 '_'로 채움 ('50__________________')
```

- **설명**:
  - **정렬 기호**:
    - `<`: 왼쪽 정렬
    - `>`: 오른쪽 정렬
    - `^`: 가운데(중앙) 정렬
  - **채움 문자 (Fill Character)**:
    - 정렬 기호 앞에 원하는 문자(예: `*`, `_`, `0` 등)를 지정하면 기본 공백 대신 해당 문자로 빈자리를 채웁니다.
    - `{0:*^10}`: 총 10칸 중 양옆 빈칸을 `*`로 채워 가운데 정렬 (`****hi****`).
    - `f'{n:_<20}'`: 총 20칸 중 오른쪽 빈칸을 `_`로 채워 왼쪽 정렬 (`50__________________`).

### 1.6 문자 개수 세기 및 위치 찾기 (`count`, `find`, `index`)

```python
# 문자열 내장 함수

# count 함수
print('hobby'.count('b'))

# find 함수
print('hobby'.find('b'))

# index 함수
print('hobby'.index('b'))
```

- **설명**:
  - **`count(문자)`**: 문자열 안에서 해당 문자가 등장한 총 횟수를 반환합니다 (`'hobby'.count('b')` $\rightarrow$ `2`).
  - **`find(문자)`**: 찾는 문자가 처음 등장하는 인덱스 번호를 반환합니다 (`'hobby'.find('b')` $\rightarrow$ `2`).
    - **중요**: 찾는 문자가 없으면 **`-1`을 반환**합니다 (에러 발생 없음).
  - **`index(문자)`**: 찾는 문자가 처음 등장하는 인덱스 번호를 반환합니다 (`'hobby'.index('b')` $\rightarrow$ `2`).
    - **중요**: 찾는 문자가 없으면 **`ValueError` 에러가 발생**합니다.

### 1.7 문자열 삽입/결합 (`join`)

```python
# join 함수
print(' '.join('hobby'))
print(', '.join(['a', 'b', 'c']))
```

- **설명**:
  - **`구분자.join(반복가능객체)`**: 문자열이나 리스트의 각 원소 사이에 앞의 구분자를 끼워 넣어 하나의 문자열로 결합합니다.
  - `' '.join('hobby')`: 글자 사이사이에 공백 삽입 $\rightarrow$ `'h o b b y'`.
  - `', '.join(['a', 'b', 'c'])`: 리스트 요소들을 쉼표와 공백으로 연결 $\rightarrow$ `'a, b, c'`.

---

### 1.8 대소문자 변환 (`upper`, `lower`)

```python
# upper 함수
print('hobby'.upper())

# lower 함수
print('hobby'.lower())
```

- **설명**:
  - **`upper()`**: 모든 소문자를 대문자로 변환합니다 (`'hobby'` $\rightarrow$ `'HOBBY'`).
  - **`lower()`**: 모든 대문자를 소문자로 변환합니다 (`'hobby'` $\rightarrow$ `'hobby'`).
  - 기존 문자열 자체를 변경하는 것이 아니라, **새롭게 변환된 문자열 객체를 반환**합니다 (문자열의 불변성).

---

### 1.9 공백 제거 (`lstrip`, `rstrip`, `strip`)

```python
# lstrip 함수
print('  hi  '.lstrip())

# rstrip 함수
print('  hi  '.rstrip())

# strip 함수
print('  hi  '.strip())
```

- **설명**:
  - **`lstrip()`**: 문자열의 **왼쪽(앞쪽)**에 있는 연속된 공백만 제거합니다 (`'hi  '`).
  - **`rstrip()`**: 문자열의 **오른쪽(뒤쪽)**에 있는 연속된 공백만 제거합니다 (`'  hi'`).
  - **`strip()`**: 문자열의 **양쪽(앞뒤)** 모든 공백을 제거합니다 (`'hi'`).
  - 사용자 입력값(input) 전처리 및 데이터 클렌징 시 빈번하게 사용됩니다.

---

### 1.10 문자열 바꾸기 (`replace`)

```python
# replace 함수
print('hobby'.replace('b', 'c'))
```

- **설명**:
  - **`replace(바꿀문자열, 새로운문자열)`**: 문자열 내의 특정 문자열을 찾아 다른 문자열로 모두 치환합니다.
  - `'hobby'.replace('b', 'c')` $\rightarrow$ `'hoccy'` (모든 `'b'`가 `'c'`로 치환됨).

---

### 1.11 문자열 나누기 (`split` 및 `maxsplit`)

```python
# split 함수
print('a b c d'.split())
print('a:b:c:d'.split(':'))
print('a:b:c:d'.split(':', 1))
print('a:b:c:d'.split(':', 2))
print('a:b:c:d'.split(':', 3))
print('a:b:c:d'.split(':', 4))
print('a:b:c:d'.split(':', 5))
```

- **설명**:
  - **`split()`**: 인자가 없으면 공백(스페이스, 탭, 줄바꿈)을 기준으로 문자열을 잘라 **리스트로 반환**합니다 (`['a', 'b', 'c', 'd']`).
  - **`split(구분자)`**: 지정한 구분자(예: `':'`)를 기준으로 문자열을 분리합니다 (`['a', 'b', 'c', 'd']`).
  - **`split(구분자, maxsplit)`**: 두 번째 인자로 **최대 분할 횟수**를 지정합니다.
    - `split(':', 1)` $\rightarrow$ 앞에서 1번만 분할하고 나머지는 그대로 유지: `['a', 'b:c:d']`
    - `split(':', 2)` $\rightarrow$ 앞에서 2번 분할: `['a', 'b', 'c:d']`
    - `split(':', 3)` $\rightarrow$ 3번 분할: `['a', 'b', 'c', 'd']`
    - 분할 횟수가 실제 구분자 개수 이상이면 전체가 분리됩니다.

## 2. 핵심 요약 및 주의사항

1. **`find()` vs `index()` 차이점 (빈출)**:
   - 찾는 문자가 **없을 때** `find()`는 **`-1`을 반환**하므로 조건문 분기에 안전합니다.
   - 반면 `index()`는 **`ValueError` 예외**를 던지므로 예외 처리가 필요합니다.
2. **문자열 불변성(Immutable)**:
   - `upper()`, `replace()`, `strip()` 등 모든 문자열 메서드는 **원본 문자열을 직접 수정하지 않고 새로운 문자열을 생성하여 반환**합니다.
3. **포매팅 3대 방식 비교**:

| 구분 | C 스타일 (`%`) | `str.format()` | f-string (`f'...'`) |
| :--- | :--- | :--- | :--- |
| **도입 시기** | 파이썬 2부터 지원 | 파이썬 2.6 / 3.0+ | 파이썬 3.6+ **(현대 표준 🌟)** |
| **기본 문법** | `'%s %d' % ('hi', 10)` | `'{} {}'.format('hi', 10)` | `f'{name} {age}'` |
| **정렬 문법** | `%-10s`, `%10s` | `'{:<10}', '{:>10}', '{:^10}'` | `f'{var:<10}', f'{var:^10}'` |
| **공백 채움** | `%06d` (0 채우기만 가능) | `'{:*^10}'` (모든 문자 가능) | `f'{var:*^10}'` (모든 문자 가능) |
| **장단점** | 단순하지만 인자가 많으면 난해함 | 인덱스/키워드 지정 가능 | **가독성 최상, 연산식 직접 삽입 가능, 가장 빠름** |
