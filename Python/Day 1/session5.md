## 1. 실습 코드 및 단계별 해설

### 1.1 리스트 선언 및 다양한 데이터 형태 수용

```python
# 리스트
# 파이썬에서는 기본 배열(Array)을 제공하지 않고 리스트를 사용
# 리스트의 특징: 순서(Sequence), 중복 허용, 수정(Mutable), 삭제 가능

list1 = []
list2 = list()

print(list1, list2)
print(type(list1), type(list2))

list3 = [1, 2, 3, 4, 5]
list4 = [1, 2, 'three', 'four', 'five']
list5 = [1, 2, ['three', 'four', 'five']] # 리스트 안에 리스트(중첩 리스트)
list6 = [1.23, 'hello', True, False, None] # 다양한 자료형 혼합 가능
list7 = list(range(1, 10)) # range()를 활용한 연속 숫자 리스트 생성

print(list4[0] + list4[1])
print(list3, list4, list5, list6, list7)
print(type(list3), type(list4), type(list5), type(list6), type(list7))

list9 = list(range(1, 10, 2))  # [1, 3, 5, 7, 9] (2씩 증가)
list10 = list(range(1, 10, 3)) # [1, 4, 7] (3씩 증가)

print(list9, list10)
print(type(list9), type(list10))
```

- **설명**:
  - `list1 = []`와 `list2 = list()`는 모두 빈 리스트를 생성합니다.
  - C/Java 등의 정적 배열과 달리, 파이썬 리스트는 **서로 다른 자료형(정수, 실수, 문자열, 불리언, None, 다른 리스트 등)을 하나의 리스트에 자유롭게 담을 수 있습니다.**
  - **`range(start, stop, step)`**:
    - `list(range(1, 10))`은 1부터 9까지의 정수 리스트를 간편하게 생성합니다.
    - `step` 값을 주어 2칸(`range(1, 10, 2)`), 3칸(`range(1, 10, 3)`) 간격으로 숫자를 건너뛰며 생성할 수 있습니다.

### 1.2 리스트 인덱싱 및 슬라이싱

```python
# list4 = [1, 2, 'three', 'four', 'five']

# 인덱싱
print(list4[1])          # 2
print(list4[0] + list4[1] + list4[1]) # 1 + 2 + 2 = 5
print(list4[-1])         # 'five' (뒤에서 첫 번째 요소)
print(list4[-1][1])      # 'five'[1] -> 'i' (문자열 요소에 대한 2차 인덱싱)

# 슬라이싱
print(list4[0:3])        # [1, 2, 'three'] (인덱스 0~2)
print(list4[2:])         # ['three', 'four', 'five'] (인덱스 2~끝)
print(list4[2][1:3])     # 'three'[1:3] -> 'hr' (문자열 슬라이싱 결합)
```

- **설명**:
  - 0부터 시작하는 순방향 인덱스와 `-1`부터 시작하는 역방향(음수) 인덱스를 지원합니다.
  - 리스트 내부에 문자열이나 또 다른 리스트가 있을 경우, `list4[-1][1]`과 같이 연속으로 괄호를 붙여 **다차원 인덱싱/슬라이싱**이 가능합니다.

### 1.3 리스트 연산 및 형 변환 주의점

```python
# list3 = [1, 2, 3, 4, 5]
# list4 = [1, 2, 'three', 'four', 'five']

# 연산
print(list3 + list4) # 두 리스트를 이어 붙여 새로운 리스트 생성
print(list3 * 3)     # 리스트 내용 3회 반복
print(str(list3[0]) + 'hi') # 1 -> '1'로 형 변환 후 문자열 연결 ('1hi')
print(list4[2] + 'hi')      # 'three' + 'hi' ('threehi')
```

- **설명**:
  - **`+` (연결)**: 두 리스트를 하나로 합쳐 새 리스트를 만듭니다.
  - **`*` (반복)**: 리스트의 원소들을 지정된 횟수만큼 복제하여 확장합니다.
  - **주의 (타입 불일치 에러)**:
    - `list3[0] + 'hi'`처럼 정수(`1`)와 문자열(`'hi'`)을 직접 `+` 연산하면 `TypeError`가 발생합니다.
    - 문자열과 연결하려면 `str(list3[0])`과 같이 명시적으로 형 변환을 해주어야 합니다.

### 1.4 리스트 요소 수정 및 삭제

```python
# 수정
list3[0] = 4
print(list3) # [4, 2, 3, 4, 5]

list3[1:2] = ['a', 'b', 'c']
print(list3) # [4, 'a', 'b', 'c', 3, 4, 5]

# 삭제
list3[1:2] = [] # 슬라이싱 범위에 빈 리스트 대입 -> 해당 구간 삭제
print(list3) # [4, 'b', 'c', 3, 4, 5]

del list3[1] # 인덱스 1 위치의 단일 요소('b') 삭제
print(list3) # [4, 'c', 3, 4, 5]

del list3[1:3] # 슬라이싱 범위(인덱스 1, 2) 삭제
print(list3) # [4, 4, 5]
```

- **설명**:
  - **단일 요소 수정**: `list3[0] = 4`와 같이 특정 인덱스에 새 값을 대입합니다.
  - **슬라이스 대입 (`list3[1:2] = ['a', 'b', 'c']`)**:
    - 특정 구간의 요소를 다른 여러 개의 요소로 교체하거나 확장할 수 있습니다.
    - `list3[1:2] = []`처럼 빈 리스트를 대입하면 해당 구간이 깔끔하게 삭제됩니다.
  - **`del` 키워드**:
    - 파이썬 내장 삭제 키워드로, `del list[인덱스]` 또는 `del list[시작:끝]` 형태로 특정 요소나 범위를 즉시 삭제합니다.

### 1.5 리스트 주요 내장 메서드

```python
a = [5, 4, 3, 2, 1]

# append : 맨 뒤에 요소 추가
a.append(6)
print(a) # [5, 4, 3, 2, 1, 6]

# sort : 오름차순 정렬 (원본 리스트 직접 수정)
a.sort()
print(a) # [1, 2, 3, 4, 5, 6]

# reverse : 순서 뒤집기 (역순 정렬이 아닌 현재 순서를 반전)
a.reverse()
print(a) # [6, 5, 4, 3, 2, 1]

# index : 값의 위치(인덱스) 반환
print(a.index(5)) # 1 (값 5가 위치한 인덱스는 1)

# insert : 특정 위치에 요소 삽입 (insert(위치, 값))
a.insert(2, 7)
print(a) # [6, 5, 7, 4, 3, 2, 1]

# remove : 특정 값의 첫 번째 요소 삭제
a.remove(1) # 리스트에서 첫 번째로 만나는 1을 제거
print(a) # [6, 5, 7, 4, 3, 2]

# pop : 마지막 요소를 꺼내어 반환하고 리스트에서 삭제
print(a.pop()) # 2 출력 (맨 뒤 요소 꺼냄)
print(a)       # [6, 5, 7, 4, 3]

# count : 특정 값의 개수 세기
print(a.count(3)) # 1

# extend : 리스트 확장 (다른 리스트의 모든 요소를 병합)
a.extend([8, 9, 10])
print(a) # [6, 5, 7, 4, 3, 8, 9, 10]
```

- **설명**:
  - **`append(값)` vs `extend(리스트)`**:
    - `append([8, 9])`는 리스트 자체를 통째로 하나의 원소로 추가(`[..., [8, 9]]`).
    - `extend([8, 9])`는 전달된 리스트의 원소들을 풀어서 각각 끝에 이어 붙임(`[..., 8, 9]`).
  - **`remove(값)` vs `pop(인덱스)`**:
    - `remove(x)`는 **값**을 기준으로 일치하는 첫 번째 원소를 제거합니다 (반환값 없음).
    - `pop()`은 **인덱스**를 기준으로 요소를 제거하며, **꺼낸 값을 반환**합니다 (인자 생략 시 마지막 요소).
  - **`sort()` vs `reverse()`**:
    - `sort()`는 크기 기준 오름차순 정렬을 수행합니다.
    - `reverse()`는 정렬 여부와 상관없이 **현재 리스트의 순서를 거꾸로 뒤집습니다.**

## 2. 핵심 요약 및 주의사항

1. **가변 객체(Mutable)**:
   - 문자열(`str`)이나 튜플(`tuple`)은 불변이므로 요소를 바꿀 수 없지만, 리스트는 자유롭게 수정/추가/삭제가 가능합니다.
2. **`sort()`와 메서드의 반환값(None)**:
   - `a.sort()`, `a.reverse()`, `a.append()` 등의 메서드는 **원본 리스트를 직접 변경(In-place modification)**하며, 반환값은 `None`입니다.
   - 따라서 `b = a.sort()`처럼 작성하면 `b`에는 아무것도 들어가지 않으니 주의해야 합니다.
3. **`remove()` 주의점**:
   - 리스트에 없는 값을 `remove()`하려 하면 `ValueError`가 발생하므로, 사전에 `if 값 in 리스트:` 체크를 하거나 예외 처리가 필요합니다.
