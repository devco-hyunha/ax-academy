## 1. 실습 코드 및 단계별 해설

### 1.1 집합 선언과 기본 특징 (중복 제거 및 순서 없음)

```python
# 집합
# 순서 없음, 중복 안됨

s1 = set()
s2 = set([1, 2, 3, 4]) # 리스트 자료형을 집합 자료형으로 변환
s3 = set([1, 4, 6, 7])
s4 = set([1, 2, 'apple', 'mango', 'python'])
s5 = {'phone', 'computer', 'notebook', 'water', 'phone'}
s6 = {12, 'mouse', (1, 2, 3), 3.14}

print( type(s1), type(s2), type(s3), type(s4), type(s5), type(s6) )
```

- **설명**:
  - `s1 = set()`: **빈 집합을 생성할 때는 반드시 `set()`을 사용**해야 합니다 (`{}`로 선언하면 빈 딕셔너리로 인식됨).
  - **중복 자동 제거**: `s5`에서 `'phone'`을 두 번 넣었으나 집합 내부에는 단 하나만 남습니다.
  - **순서 없음(Unordered)**: 인덱스가 존재하지 않으므로 순서를 보장하지 않습니다.
  - **원소의 조건**: 집합의 원소는 해시 가능(Hashable)한 불변(Immutable) 객체여야 합니다. 숫자, 문자열, 불리언, 튜플(`(1, 2, 3)`)은 원소로 들어갈 수 있지만, **가변 객체인 리스트나 딕셔너리는 집합의 원소가 될 수 없습니다.**

### 1.2 집합의 형 변환 (인덱싱 및 슬라이싱 활용)

```python
t = tuple(s2)
print(t, type(t), s2)
print(t[0], t[1:3])

# list로 변환 할 때, 입력한 순서가 유지 안됨
li1 = list(s3)
li2 = list(s4)
print(li1, type(li1))
print(li2, type(li2))
```

- **설명**:
  - 집합은 순서가 없으므로 `s2[0]`과 같은 **직접 인덱싱/슬라이싱이 불가능**합니다 (`TypeError` 발생).
  - 특정 요소에 인덱스로 접근하려면 `tuple()`이나 `list()`로 형 변환한 후 조회해야 합니다.
  - **주의**: 리스트/튜플로 변환할 때 집합 내부의 해시 정렬에 따라 원소 순서가 재배치되므로, **원래 입력했던 순서가 유지되지 않을 수 있습니다.**

### 1.3 기본 집합 연산 (교집합, 합집합, 차집합)

```python
set1 = set([1, 2, 3, 4, 5, 6])
set2 = set([4, 5, 6, 7 ,8, 9])

# 교집합
print(set1 & set2)
print(set1.intersection(set2))

# 합집합
print(set1 | set2)
print(set1.union(set2))

# 차집합
print(set1 - set2)
print(set1.difference(set2))
```

- **설명**:
  - **교집합 (Intersection)**:
    - 기호: `set1 & set2`
    - 메서드: `set1.intersection(set2)`
    - 두 집합에 공통으로 속하는 원소 반환: `{4, 5, 6}`
  - **합집합 (Union)**:
    - 기호: `set1 | set2`
    - 메서드: `set1.union(set2)`
    - 두 집합의 모든 원소를 중복 없이 합쳐 반환: `{1, 2, 3, 4, 5, 6, 7, 8, 9}`
  - **차집합 (Difference)**:
    - 기호: `set1 - set2`
    - 메서드: `set1.difference(set2)`
    - `set1`에서 `set2`와의 공통 원소를 제거한 나머지 반환: `{1, 2, 3}`

### 1.4 집합 관계 검사 (서로소, 부분집합, 상위집합)

```python
# 두 집합이 서로소인지 확인
print(set1.isdisjoint(set2))

# 부분집합 확인
print(set1.issubset(set2))

# 상위집합 확인
print(set1.issuperset(set2))
```

- **설명**:
  - **`isdisjoint()` (서로소 검사)**:
    - 두 집합 사이에 공통 원소가 하나도 없으면 `True`, 하나라도 겹치면 `False`를 반환합니다.
    - `set1`과 `set2`는 `{4, 5, 6}`이 겹치므로 `False`를 반환합니다.
  - **`issubset()` (부분집합 검사)**:
    - `set1`의 모든 원소가 `set2`에 포함되어 있는지 확인합니다 (`set1 ⊆ set2`).
    - 여기서는 일부만 포함되므로 `False`를 반환합니다.
  - **`issuperset()` (상위집합 검사)**:
    - `set1`이 `set2`의 모든 원소를 포함하고 있는지 확인합니다 (`set1 ⊇ set2`).
    - 여기서는 `False`를 반환합니다.

### 1.5 요소 추가 및 삭제 메서드

```python
a = set([1, 2, 3, 4])

# 단일 요소 추가
a.add(5)
print(a) # {1, 2, 3, 4, 5}

# 다중 요소 추가
a.update([6, 7, 8])
print(a) # {1, 2, 3, 4, 5, 6, 7, 8}

# 요소 삭제 (remove vs discard)
# 요소가 없으면 에러 발생
a.remove(5)
# 요소가 없어도 에러 발생 안함
a.discard(6)

# 모든 요소 삭제
a.clear()
print(a) # set()
```

- **설명**:
  - **`add(값)`**: 단일 원소 1개를 추가합니다.
  - **`update([값들])`**: 리스트, 튜플 등 반복 가능 객체의 여러 요소를 한 번에 추가합니다.
  - **`remove(값)` vs `discard(값)` (핵심 차이점)**:
    - `remove(x)`: 삭제하려는 원소가 집합에 없으면 **`KeyError` 예외가 발생**합니다.
    - `discard(x)`: 삭제하려는 원소가 집합에 **없어도 에러 없이 정상 통과**합니다.
  - **`clear()`**: 집합의 모든 원소를 삭제하여 빈 집합 `set()`으로 만듭니다.

## 2. 핵심 요약 및 복습 포인트

| 연산 / 메서드 | 문법 예시 | 연산자 / 기호 | 특징 및 주의사항 |
| :--- | :--- | :--- | :--- |
| **빈 집합 선언** | `s = set()` | - | `{}`로 선언 시 빈 딕셔너리가 되므로 주의 |
| **교집합** | `s1.intersection(s2)` | `s1 & s2` | 공통 원소 추출 |
| **합집합** | `s1.union(s2)` | `s1 \| s2` | 중복 제거 합치기 |
| **차집합** | `s1.difference(s2)` | `s1 - s2` | 앞 집합에서 공통 원소 제거 |
| **서로소 검사** | `s1.isdisjoint(s2)` | - | 공통 원소가 없으면 `True` |
| **부분집합 검사** | `s1.issubset(s2)` | `s1 <= s2` | `s1`이 `s2`에 포함되는지 확인 |
| **상위집합 검사** | `s1.issuperset(s2)` | `s1 >= s2` | `s1`이 `s2`를 포함하는지 확인 |
| **단일 추가** | `s.add(x)` | - | 원소 1개 추가 |
| **다중 추가** | `s.update([x, y])` | - | 여러 원소 동시 병합 |
| **안전 삭제** | `s.discard(x)` | - | 원소가 없어도 에러 없음 |
| **엄격 삭제** | `s.remove(x)` | - | 원소가 없으면 `KeyError` 발생 |
