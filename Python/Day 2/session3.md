### 1.1 변수의 메모리 주소 확인(`id`)과 객체 동일성 검사(`is`)

```python
# id
a = 3
print(id(3))
print(id(a))

b = a
print(id(b))
print(b is a) # 같은 객체를 가리키고 있는지 확인
```

- **설명**:
  - **`id(객체)`**: 객체가 메모리상에 저장된 고유 주소값(정수)을 반환합니다.
  - `a = 3`: 숫자 `3`이라는 객체가 메모리에 생성되고, 변수 `a`는 그 메모리 주소를 가리킵니다(참조). 따라서 `id(3)`과 `id(a)`는 동일합니다.
  - `b = a`: 변수 `b` 역시 변수 `a`가 가리키고 있는 동일한 객체 `3`의 메모리 주소를 참조합니다.
  - **`b is a`**: 두 변수가 단순히 값이 같은지(`==`)가 아니라, **실제 메모리상에서 동일한 객체를 가리키고 있는지**를 검사하여 `True`를 반환합니다.

### 1.2 얕은 복사 (`copy`)

```python
# 얕은 복사
# from [모듈] import [함수] - 외부 모듈에서 함수를 가져오는 문법
from copy import copy

a2 = [1, 2, 3]
b2 = copy(a2)
print(b2 is a2) # False (서로 다른 객체)
print(id(a2))
print(id(b2))
```

- **설명**:
  - `b = a` 형태로 대입하면 두 변수가 같은 리스트를 참조하여 한쪽을 수정하면 다른 쪽도 함께 바뀝니다.
  - **`copy(a2)` (또는 `a2[:]`)**: 리스트의 내용을 복사하여 **새로운 독립적인 리스트 객체를 생성**합니다.
  - 따라서 `a2`와 `b2`는 값은 같지만 메모리 주소(`id`)가 서로 다르며, `b2 is a2`의 결과는 `False`가 됩니다.

### 1.3 되새김 문제 1: 딕셔너리를 활용한 평균 점수 계산

```python
# 1. 평균 점수 구하기
sco = {
  'korean': 80,
  'english': 75,
  'math': 55
}

sum = 0
for value in sco.values():
  sum += value

print(sum / len(sco)) # 평균: 70.0
```

- **설명**:
  - `sco.values()` 메서드를 통해 과목별 점수만 반복문으로 꺼내어 누적 합산(`sum += value`)합니다.
  - 누적합을 과목 수(`len(sco)`)로 나누어 평균 점수(70.0)를 계산합니다.

### 1.5 되새김 문제 5: 문자열 치환 (`replace`)

```python
# 5. 문자열 바꾸기
a = "a:b:c:d"
b = a.replace(':', '#')
print(b) # "a#b#c#d"
```

- **설명**:
  - `replace(old, new)` 메서드를 사용하여 콜론(`:`)을 샵(`#`)으로 일괄 치환합니다.
  - 문자열은 불변 객체이므로 원본 `a`는 변경되지 않고, 치환된 새 문자열이 반환되어 `b`에 저장됩니다.

### 1.6 되새김 문제 6: 리스트 정렬 및 역순 정렬

```python
# 6. 리스트 역순 정렬
a = [1, 3, 5, 4, 2]
a.sort()
print(a) # [1, 2, 3, 4, 5] (오름차순 정렬)
a.reverse()
print(a) # [5, 4, 3, 2, 1] (현재 상태 기준 순서 뒤집기)
```

- **설명**:
  - `a.sort()`: 원본 리스트를 오름차순으로 정렬합니다.
  - `a.reverse()`: 현재 리스트의 순서를 거꾸로 뒤집어 결과적으로 내림차순 정렬(`[5, 4, 3, 2, 1]`)을 완성합니다.
  - *대안*: `a.sort(reverse=True)`를 실행하면 한 번에 내림차순 정렬이 가능합니다.

### 1.8 되새김 문제 8: 튜플에 요소 추가하기

```python
# 8. 튜플 더하기
a = (1, 2, 3)
a += (4,)
print(a) # (1, 2, 3, 4)
```

- **설명**:
  - 튜플은 불변 객체이므로 내부 요소를 직접 추가/수정할 수 없습니다.
  - 새로운 요소를 추가하려면 단일 원소 튜플 `(4,)`를 `+` 연산자로 연결하여 **새로운 튜플을 만들어 재할당**해야 합니다. (단일 요소 튜플 선언 시 쉼표 필수)

### 1.9 되새김 문제 9: 딕셔너리 Key로 사용 가능한 자료형

```python
# 9. 딕셔너리 키
a = dict()
a['name'] = 'python'   # 가능 (문자열: 불변)
a[('a', )] = 'python'  # 가능 (튜플: 불변)
a[250] = 'python'      # 가능 (정수: 불변)
# a[[1]] = 'python'    # 불가능: TypeError: unhashable type: 'list' (리스트: 가변)
```

- **설명**:
  - 딕셔너리의 Key는 **해시 가능(Hashable)한 불변(Immutable) 객체**만 허용됩니다.
  - 문자열(`str`), 숫자(`int`, `float`), 튜플(`tuple`)은 Key로 사용 가능합니다.
  - **리스트(`list`)나 딕셔너리(`dict`)**는 가변 객체이므로 Key로 사용 시 `TypeError: unhashable type` 에러가 발생합니다.

### 1.10 되새김 문제 10: 딕셔너리 요소 꺼내기 (`pop`)

```python
# 10. 딕셔너리 값 추출
a = { 'A': 90, 'B': 80, 'C': 70 }
result = a.pop('B')
print(a)      # {'A': 90, 'C': 70}
print(result) # 80
```

- **설명**:
  - `a.pop('B')`: 딕셔너리에서 키 `'B'`에 해당하는 값을 반환(`80`)하면서 딕셔너리에서 해당 키-값 쌍을 삭제합니다.

### 1.11 되새김 문제 11: 집합을 이용한 리스트 중복 제거

```python
# 11. 리스트 중복 제거
a = [1, 1, 1, 2, 2, 3, 3, 3, 4, 5, 5]
aSet = set(a)  # {1, 2, 3, 4, 5} (중복 제거)
b = list(aSet) # 다시 리스트로 변환
print(b)       # [1, 2, 3, 4, 5]
```

- **설명**:
  - `set()` 자료형은 중복을 허용하지 않는 특성이 있습니다.
  - 리스트를 `set()`으로 감싸 중복을 제거한 뒤 다시 `list()`로 감싸면 중복이 제거된 깔끔한 리스트를 얻을 수 있습니다. (실무 및 코딩 테스트 빈출 패턴)

### 1.12 되새김 문제 12: 변수 할당과 가변 객체 참조 공유

```python
# 12. 파이썬 변수 참조
a = b = [1, 2, 3] # a와 b가 완전히 동일한 리스트 메모리 주소를 공유
a[1] = 4
print(b) # [1, 4, 3]
```

- **설명**:
  - `a = b = [1, 2, 3]`을 실행하면 두 변수는 별개의 리스트를 가지는 것이 아니라, 메모리상에 하나만 존재하는 리스트 객체의 주소를 함께 가리킵니다(`id(a) == id(b)`).
  - 리스트는 가변 객체이므로 `a[1] = 4`로 값을 바꾸면 동일 객체를 참조하는 `b`의 출력 결과도 `[1, 4, 3]`으로 함께 변경됩니다.

## 2. 핵심 요약 및 복습 포인트

| 개념 / 문제 | 핵심 원리 | 주의사항 |
| :--- | :--- | :--- |
| **`id()` & `is`** | 메모리 주소 확인 및 동일 객체 참조 여부 검사 | `==` (값 일치 비교) vs `is` (메모리 주소 일치 비교) |
| **얕은 복사** | `copy(a)` 또는 `a[:]`로 새 독립 객체 생성 | `b = a`는 참조 복사이므로 수정 시 동시 반영됨 |
| **딕셔너리 Key** | 불변(Immutable) 타입만 가능 (`str`, `int`, `tuple`) | `list`, `dict`, `set`은 Key로 사용 불가 (`TypeError`) |
| **중복 제거 패턴** | `list(set(target_list))` | 리스트의 중복 값을 가장 쉽고 빠르게 제거하는 표준 패턴 |
| **튜플 확장** | `t += (요소,)` 단일 원소 튜플 결합 | 요소가 1개인 튜플은 반드시 쉼표(`,`)를 붙여야 함 |
| **딕셔너리 pop** | `val = dic.pop('key')` | 값을 반환함과 동시에 딕셔너리에서 해당 항목을 삭제 |
