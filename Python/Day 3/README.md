## 1. Day 3 핵심 문법 및 기법 비교 (Quick Reference)

### 1.1 반복문 비교: `while` vs `for`

| 구분 | `while` 문 | `for` 문 |
| :--- | :--- | :--- |
| **주요 사용처** | 특정 조건이 참인 동안 반복 (횟수가 정해지지 않은 경우, 무한 루프) | 리스트, 튜플, 문자열, `range()` 등 정해진 시퀀스를 순회할 때 |
| **카운터 변수** | 루프 외부에서 선언하고 루프 내부에서 직접 증감(`i += 1`) | `in` 뒤의 이터러블이나 `range()`를 통해 자동 증감 |
| **`else` 지원** | `break` 없이 정상 종료 시 `else` 블록 실행 | `break` 없이 정상 종료 시 `else` 블록 실행 |

### 1.2 함수의 인자(Parameters) 종류 비교

| 종류 | 문법 예시 | 특징 |
| :--- | :--- | :--- |
| **일반 위치 인자** | `def f(a, b):` | 순서대로 매핑 |
| **기본값 인자** | `def f(a, b=10):` | 인자 생략 시 기본값 사용 (반드시 일반 인자 뒤에 배치) |
| **위치 가변 인자** | `def f(*args):` | 임의 개수의 위치 인자를 **튜플(tuple)**로 수집 |
| **키워드 가변 인자** | `def f(**kwargs):` | 임의 개수의 `key=val` 인자를 **딕셔너리(dict)**로 수집 |

## 2. Day 3 핵심 복습 포인트 (Cheat Sheet)

1. **`for-else` 및 `while-else`**:
   - 루프 내부에서 `break`를 만나지 않고 정상적으로 끝까지 실행되었을 때만 `else` 블록이 실행됩니다.
2. **리스트 컴프리헨션**:
   - `[표현식 for 항목 in 반복가능객체 if 조건문]` 형태로 간결하고 빠른 리스트 생성을 지원합니다.
3. **함수의 다중 반환값**:
   - `return a, b, c`는 실제로는 하나의 튜플 `(a, b, c)`로 반환되며, `x, y, z = f()` 형태로 언패킹하여 받을 수 있습니다.
4. **가변 인자 선언 순서**:
   - `(일반 매개변수, *args, **kwargs)` 순서를 엄격히 지켜야 합니다.
5. **C 스타일 포매팅에서 `%` 기호 출력**:
   - 일반 문자로 퍼센트 기호를 표시하려면 반드시 `%%`로 작성해야 합니다 (`'%d%%' % 10`).
6. **`input()`의 반환값 타입**:
   - 숫자를 입력해도 항상 문자열(`str`)로 반환되므로, 연산이 필요할 때는 `int(input())`으로 형 변환해야 합니다.
