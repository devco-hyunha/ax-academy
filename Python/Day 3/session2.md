## 1. 실습 코드 및 단계별 해설

### 1.1 리스트 컴프리헨션 기본 문법

```python
# 기존 for 문 방식
a = [1, 2, 3, 4]
result = []
for num in a:
  result.append(num * 3)
print(result) # [3, 6, 9, 12]

# 리스트 컴프리헨션 방식
a = [1, 2, 3, 4]
result = [num * 3 for num in a]
print(result) # [3, 6, 9, 12]
```

- **설명**:
  - 리스트 컴프리헨션(List Comprehension)은 리스트 안에 `for`문을 포함하여 새로운 리스트를 한 줄로 간결하게 생성하는 파이썬 특유의 강력한 문법입니다.
  - **기본 구조**: `[표현식 for 항목 in 반복가능객체]`
  - 코드가 3~4줄에서 1줄로 단축되며, 내부적으로 최적화되어 일반 `append()` 반복보다 **실행 속도도 더 빠릅니다.**

### 1.2 조건문(`if`) 필터링이 포함된 리스트 컴프리헨션

```python
# 1부터 30까지의 수 중 3의 배수만 추출
b2 = [i for i in range(1, 31) if i % 3 == 0]
print(b2) # [3, 6, 9, 12, 15, 18, 21, 24, 27, 30]
```

- **설명**:
  - **조건부 구조**: `[표현식 for 항목 in 반복가능객체 if 조건문]`
  - `range(1, 31)`에서 숫자를 하나씩 꺼내며 `if i % 3 == 0` 조건을 만족하는 값만 최종 리스트에 포함시킵니다.

### 1.3 중첩 `for` 루프 리스트 컴프리헨션 (구구단 전체 연산)

```python
result = [
  x * y
    for x in range(2, 10)
      for y in range(1, 10)
]
print(result)
```

- **설명**:
  - 여러 개의 `for`문을 연속으로 나열할 수 있습니다.
  - 첫 번째 `for x in range(2, 10)`가 외부 루프, 두 번째 `for y in range(1, 10)`가 내부 루프 역할을 하여 $2 \times 1$부터 $9 \times 9$까지 총 72개의 연산 결과가 담긴 리스트를 생성합니다.

### 1.4 되새김 문제 1: 조건문의 `elif` 평가 순서

```python
a = 'Life is too short, you need python'

if 'wife' in a: print('wife')
elif 'python' in a and 'you' not in a: print('python')
elif 'shirt' not in a: print('shirt')
elif 'need' in a: print('need')
else: print('none')
# 출력 결과 : shirt
```

- **설명**:
  1. `'wife' in a`: `'wife'`가 없으므로 `False`.
  2. `'python' in a and 'you' not in a`: `'python'`은 있지만 `'you'`도 문자열에 포함되어 있으므로 `False`.
  3. `'shirt' not in a`: `'shirt'`라는 단어는 문자열 `a`에 실제로 없으므로 조건식이 **`True`**가 됩니다!
  4. 따라서 세 번째 조건에서 `'shirt'`를 출력하고 `if-elif` 전체 구문이 종료됩니다 (뒤의 `'need' in a`는 검사되지 않음).

### 1.5 되새김 문제 2: `while` 문으로 1~1000 중 3의 배수의 합 구하기

```python
result = 0
i = 1
while i <= 1000:
  if i % 3 == 0:
    result += i
  i += 1
print(result) # 166833
```

- **설명**:
  - `i`를 1부터 1000까지 증가시키면서, `i % 3 == 0`인 경우에만 누적 변수 `result`에 더합니다.
  - 반복이 끝난 후 1부터 1000까지 모든 3의 배수의 총합인 `166833`이 출력됩니다.

### 1.6 되새김 문제 3: `while` 문을 활용한 별(`*`) 계단 출력

```python
# *
# **
# ***
# ****
# *****
i = 0
while True:
  i += 1
  if (i > 5):
    break
  print('*' * i)
```

- **설명**:
  - 문자열 반복 연산자 `*`를 활용하여 `'*' * i`로 별을 `i`개 출력합니다.
  - `while True` 무한 루프에서 `i`가 5를 초과하는 순간 `break`로 루프를 탈출합니다.

### 1.7 되새김 문제 4: `for` 문으로 1부터 100까지 가로 출력

```python
for i in range(1, 101):
  print(i, end = ' ')
print()
```

- **설명**:
  - `range(1, 101)`로 1부터 100까지의 숫자를 생성합니다.
  - `end = ' '` 옵션을 통해 줄바꿈 없이 공백으로 구분하여 한 줄로 나열합니다.

---

### 1.8 되새김 문제 5: `for` 문을 활용한 학급 평균 점수 계산

```python
A = [70, 60, 55, 75, 95, 90, 80, 85, 100]
total = 0
for score in A:
  total += score
average = total / len(A)
print(average) # 78.88888888888889
```

- **설명**:
  - `total` 변수에 각 학생의 점수를 순차적으로 누적 합산합니다.
  - 총합을 리스트의 길이 `len(A)`(학생 수 9명)로 나누어 평균값을 구합니다.

### 1.9 되새김 문제 6: 리스트 컴프리헨션 변환 (홀수만 2배 곱하기)

```python
# 원본 코드:
# numbers = [1, 2, 3, 4, 5]
# result = []
# for n in numbers:
#   if n % 2 == 1:
#     result.append(n * 2)

# 리스트 컴프리헨션으로 변환:
result = [n * 2 for n in [1, 2, 3, 4, 5] if n % 2 == 1]
print(result) # [2, 6, 10]
```

- **설명**:
  - 리스트 `[1, 2, 3, 4, 5]` 중 홀수(`1, 3, 5`)만 필터링한 뒤 각각 2를 곱하여 `[2, 6, 10]`을 반환합니다.
  - `if n % 2 == 1` 조건문이 `for`문 뒤에 위치하여 홀수만 선택합니다.
