## 1. Day 4 핵심 문법 및 기법 비교 (Quick Reference)

### 1.1 함수 정의 방식: `def` vs `lambda`

| 구분 | 일반 함수 (`def`) | 람다 표현식 (`lambda`) |
| :--- | :--- | :--- |
| **문법** | `def name(args): return expr` | `lambda args: expr` |
| **이름** | 고유한 함수 이름을 가짐 | 기본적으로 익명(Anonymous) |
| **복잡도** | 여러 줄의 복잡한 로직, 조건 분기 가능 | 단일 표현식의 평가 결과만 즉시 반환 |
| **주요 사용처** | 재사용되는 핵심 로직, 모듈 함수 | `map()`, `filter()`, 정렬 `key` 등 일회성 콜백 인자 |

### 1.2 데이터 변환/필터링 3대 기법 비교

| 기법 | 요소 변환 (Transformation) | 조건 필터링 (Filtering) |
| :--- | :--- | :--- |
| **함수형 내장 함수** | `map(func, iterable)` | `filter(predicate, iterable)` |
| **리스트 컴프리헨션 🌟** | `[func(x) for x in iterable]` | `[x for x in iterable if condition]` |
| **특징 및 권장사항** | 지연 평가 이터레이터 반환 | 파이썬에서는 가독성과 속도 면에서 **리스트 컴프리헨션을 표준 권장** |

---

### 1.3 객체지향 프로그래밍: 클래스 변수 vs 인스턴스 변수

| 구분 | 클래스 변수 | 인스턴스 변수 |
| :--- | :--- | :--- |
| **선언 위치** | 클래스 블록 내부 (메서드 밖) | 메서드 내부 (`self.변수명 = 값`) |
| **소유권** | 클래스 자체 및 모든 인스턴스가 공유 | 해당 인스턴스 객체만 단독 소유 |
| **접근 방식** | `클래스명.변수명` 또는 `인스턴스.변수명` | `인스턴스.변수명` |
| **용도** | 모든 객체가 공유해야 하는 공통 상수나 카운터 | 각 객체마다 달라야 하는 고유 상태값 |

## 2. Day 4 핵심 복습 포인트 (Cheat Sheet)

1. **변수 스코프**:
   - 함수 내부에서 정의된 변수는 기본적으로 지역 변수(Local Variable)이며, 외부 전역 변수의 값을 직접 바꾸지 않습니다.
2. **일급 객체 함수(First-Class Function)**:
   - 파이썬에서 함수는 변수에 할당(`a = multi`)하거나 다른 함수의 인자(`final(1, 2, multi)`)로 전달할 수 있습니다.
3. **`all()` vs `any()`의 빈 값 판정**:
   - `all([])` $\rightarrow$ `True` (거짓인 원소가 하나도 없으므로 참)
   - `any([])` $\rightarrow$ `False` (참인 원소가 하나도 없으므로 거짓)
4. **`chr()` vs `ord()`**:
   - `chr(97)` $\rightarrow$ `'a'` (유니코드 정수 $\rightarrow$ 문자)
   - `ord('a')` $\rightarrow$ `97` (문자 $\rightarrow$ 유니코드 정수)
5. **`zip()` 함수**:
   - 동일 인덱스의 요소들을 묶어 튜플로 반환하며, `dict(zip(keys, values))` 형태로 딕셔너리 생성을 한 줄로 완료할 수 있습니다.
6. **파일 읽기 메서드 구분**:
   - `readline()`: 한 줄만 문자열로 읽기 (메모리 절약)
   - `readlines()`: 모든 줄을 읽어 각 줄을 원소로 하는 **리스트** 반환
   - `read()`: 파일 내용 전체를 **단일 문자열**로 통째로 읽기
7. **파일 포인터와 자원 해제**:
   - 파일을 읽을 때마다 커서(포인터)가 이동하며, 사용 완료 후에는 반드시 `f.close()` 또는 `with` 문을 활용해 자원을 해제해야 합니다.
8. **클래스(Class)와 객체/인스턴스 및 `self`**:
   - 객체는 파이썬의 모든 데이터 실체이며, 인스턴스는 특정 클래스와의 소속 관계를 표현합니다.
   - `self`는 호출한 인스턴스 자신을 가리키며, 인스턴스 메서드 호출(`t.func()`) 시 자동으로 첫 번째 인자로 전달됩니다.
