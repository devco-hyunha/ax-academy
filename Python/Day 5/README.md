## 1. Day 5 핵심 문법 및 기법 비교 (Quick Reference)

### 1.1 메서드 상속 vs 메서드 오버라이딩

| 구분 | 상속 후 기능 확장 (Extension) | 메서드 오버라이딩 (Overriding) |
| :--- | :--- | :--- |
| **개념** | 부모 클래스에 없는 새로운 메서드를 자식 클래스에 추가 | 부모 클래스에 이미 존재하는 메서드를 자식 클래스에서 재정의 |
| **구현 예시** | `UpgradeCalculator.minus()` | `MaxLimitCalcurator.add()` |
| **부모 메서드 호출** | 부모의 기존 메서드는 자식 인스턴스에서 그대로 호출 가능 | 필요 시 `super().메서드명()`으로 부모 로직을 선행/후행 실행 |
| **목적** | 기존 기능을 유지하면서 새로운 동작을 덧붙임 | 기존 부모의 동작 방식을 변경하거나 제약 조건을 추가함 |

### 1.2 모듈 실행 방식: 직접 실행 vs 임포트 실행

| 구분 | 직접 실행 (`python script.py`) | 모듈로 임포트 (`import script`) |
| :--- | :--- | :--- |
| **내장 변수 `__name__`** | `"__main__"` | `"script"` (해당 모듈/파일명) |
| **`if __name__ == "__main__":` 블록** | **실행됨** | **실행되지 않고 건너뜀** |
| **주요 목적** | 독립적인 프로그램 실행, 단위 테스트, 디버깅 | 함수/클래스 라이브러리 제공 및 코드 재사용 |

### 1.3 객체 저장 방식: 텍스트 파일 vs Pickle 직렬화

| 구분 | 일반 텍스트 입출력 (`open(..., 'w')`) | 피클 바이너리 입출력 (`pickle.dump(..., 'wb')`) |
| :--- | :--- | :--- |
| **저장 데이터** | 문자열(str)만 가능 (숫자/딕셔너리는 문자열로 변환 필요) | 파이썬 객체 원형(dict, list, class 인스턴스 등) 그대로 저장 |
| **파일 열기 모드** | 텍스트 모드 (`'w'`, `'r'`) | 바이너리 모드 (`'wb'`, `'rb'`) |
| **읽어올 때 처리** | 문자열 파싱(parsing) 필요 | `pickle.load()`로 즉시 파이썬 객체로 역직렬화 복원 |

## 2. Day 5 핵심 복습 포인트 (Cheat Sheet)

1. **`super()`의 역할**:
   - 자식 클래스에서 부모 클래스의 메서드나 생성자를 호출할 때 사용하며, 중복 코드를 없애고 객체 초기화 계층 구조를 안전하게 유지합니다.
2. **`__dict__` 속성**:
   - 객체나 클래스가 보유한 속성(네임스페이스)을 딕셔너리로 반환합니다. 인스턴스 변수와 클래스 변수가 저장되는 물리적 공간이 구분됨을 확인할 수 있습니다.
3. **`time.strftime()` 형식 지정**:
   - 날짜와 시간을 포맷팅할 때 `%Y`(연도), `%m`(월), `%d`(일), `%H`(시), `%M`(분), `%S`(초) 지정자를 결합하여 원하는 문자열로 출력합니다.
4. **`random.shuffle()` vs `random.choice()` vs `random.randint()`**:
   - `shuffle(list)`: 리스트 원소를 제자리(in-place)에서 무작위로 섞음
   - `randint(a, b)`: $a \le N \le b$ 범위의 정수 난수 생성
5. **얼리 리턴(Early Return)**:
   - 계좌 출금(`Account.withdraw`)과 같이 잔액 검증 조건 미충족 시 즉시 `return` 처리하여 중첩 if문을 줄이고 코드 가독성을 극대화합니다.
