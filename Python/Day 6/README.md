## 1. Day 6 핵심 문법 및 기법 비교 (Quick Reference)

### 1.1 모듈 임포트 방식 비교

| 구분 | `import 패키지.모듈` | `from 패키지 import 모듈 as 별칭` | `from 패키지 import *` |
| :--- | :--- | :--- | :--- |
| **호출 문법** | `패키지.모듈.함수()` | `별칭.함수()` | `함수()` |
| **네임스페이스** | 모듈 전체 경로 보존 (안전) | 축약된 별칭 사용 (가독성 우수) | 현재 네임스페이스로 모두 복사 (충돌 위험) |
| **`__init__.py` 의존도** | 낮음 | 낮음 | **매우 높음 (`__all__` 지정 필수)** |

---

### 1.2 함수형 데코레이터 vs 클래스형 데코레이터

| 구분 | 함수형 데코레이터 (`def trace`) | 클래스형 데코레이터 (`class Tr`) |
| :--- | :--- | :--- |
| **선언 방식** | 외부 함수 + 내부 클로저 `wrapper` | `__init__` + `__call__` 매직 메서드 |
| **상태 유지** | 외부 함수의 자유 변수(Closure) 활용 | 인스턴스 속성(`self.변수`)으로 영속적 유지 용이 |
| **동작 메커니즘** | 함수가 다른 함수를 래핑하여 반환 | 인스턴스 자체가 호출 가능한 객체가 되어 실행 |

---

### 1.3 예외 처리 제어 흐름 (`try - except - else - finally`)

```
          [ try 블록 진입 ]
                  │
          예외 발생 여부 판별
           ┌──────┴──────┐
       [예외 발생]    [정상 실행]
           │             │
     [ except 블록 ]  [ else 블록 ]
           └──────┬──────┘
                  │
           [ finally 블록 ] (항상 무조건 실행)
```

## 2. Day 6 핵심 복습 포인트 (Cheat Sheet)

1. **`__init__.py`와 `__all__`**:
   - `from package import *` 사용 시 외부에 공개할 모듈/심볼 목록을 `__all__ = ['module1', ...]` 형태로 명시해야 불필요한 네임스페이스 오염을 방지할 수 있습니다.
2. **사용자 정의 예외 선언**:
   - `class MyError(Exception):` 형태로 상속받아 정의하며, `__str__()` 메서드를 오버라이딩하여 에러 메시지를 커스터마이징합니다.
3. **`raise` 키워드**:
   - 비즈니스 유효성 검사에서 조건에 어긋나는 경우(예: 음수 나이, 비허용 닉네임) 개발자가 직접 예외를 발생시킬 때 사용합니다.
4. **`__call__` 매직 메서드**:
   - 인스턴스 객체를 일반 함수처럼 소괄호 `()`로 실행 가능하게 만들어주며, 객체의 내부 상태를 보존하면서 동작을 유연하게 제어할 수 있습니다.
5. **데코레이터 문법 (`@decorator`)**:
   - 기존 함수의 코드를 변경하지 않고도 실행 전후 로깅, 파라미터 출력, 권한 검사 등의 부가 기능을 덧붙일 수 있습니다 (`wrapper(*args, **kwargs)` 구조 필수).
