## 1. Day 7 핵심 문법 및 기법 비교 (Quick Reference)

### 1.1 이터러블(Iterable) vs 이터레이터(Iterator) vs 제너레이터(Generator)

| 구분 | 이터러블 (Iterable) | 이터레이터 (Iterator) | 제너레이터 (Generator) |
| :--- | :--- | :--- | :--- |
| **정의** | 반복 가능한 모든 객체 (리스트, 튜플 등) | `next()` 호출 시 다음 값을 반환하는 객체 | `yield`를 사용해 이터레이터를 생성하는 함수 |
| **필수 메서드** | `__iter__()` 제공 | `__iter__()` + `__next__()` 구현 | `yield` 포함 (프로토콜 자동 구현) |
| **동작 특징** | 여러 번 처음부터 순회 가능 | 1회 소비되면 재순회 불가 (Exhaustion) | 필요할 때만 계산하는 지연 평가(Lazy Evaluation) |
| **메모리 사용** | 모든 데이터를 메모리에 보유 | 상태 변수만 유지하여 메모리 절약 | 계산식과 현재 상태만 유지하여 대용량/무한 수열에 최적화 |

### 1.2 객체 저장 방식: 텍스트 파일 vs JSON vs Pickle

| 구분 | 텍스트 파일 (`score1.txt`) | JSON 파일 (`stu.json`) | Pickle 바이너리 (`*.obj`) |
| :--- | :--- | :--- | :--- |
| **저장 형식** | 단순 문자열 (CSV 등) | 경량 텍스트 (범용 표준 JSON) | 파이썬 전용 바이트 스트림 |
| **타 언어 호환** | 파싱 규칙에 따라 가능 | **매우 높음 (웹/API 표준)** | 파이썬 환경에서만 호환 |
| **읽기/쓰기 모드** | 텍스트 모드 (`'r'`, `'w'`, `'a'`) | 텍스트 모드 (`'r'`, `'w'`) | 바이너리 모드 (`'rb'`, `'wb'`) |
| **장점** | 구조가 단순함 | 범용성, 사람이 읽고 편집하기 용이 | 파이썬 복합 객체/클래스 원형 보존 |

## 2. Day 7 핵심 복습 포인트 (Cheat Sheet)

1. **`__str__()` 메서드**:
   - `print(obj)`나 `str(obj)` 호출 시 객체를 사람이 읽기 쉬운 문자열 형태로 변환하여 반환합니다.
2. **`with open(...)` 문**:
   - 블록을 벗어나는 순간 예외 발생 여부와 무관하게 자동으로 `close()`되므로 파일 누수(Resource Leak)를 방지합니다.
3. **제너레이터의 무한 수열 처리 (`while True` + `yield`)**:
   - `while True` 문이라도 `yield`를 만나면 연산을 일시 정지하고 호출자에게 값을 방출하므로 무한 루프에 빠지지 않고 필요할 때마다 짝수나 번호를 하나씩 생성할 수 있습니다.
4. **데코레이터를 통한 권한 검증**:
   - 로그인 상태 확인(`login_state`)과 같은 공통 검증 로직을 함수 본체와 분리하여 데코레이터(`@login`)로 감싸면 중복을 제거하고 가독성을 높일 수 있습니다.
5. **`json.dump()` 주요 옵션**:
   - `ensure_ascii=False`: 한글 유니코드 이스케이프 방지 (한글 원문 저장)
   - `indent=2`: 사람이 읽기 좋게 들여쓰기 서식 적용
6. **`sys.exit()`**:
   - 예외 상황이나 작업 완료 후 더 이상의 코드 실행 없이 즉시 파이썬 인터프리터 프로세스를 종료할 때 사용합니다.
