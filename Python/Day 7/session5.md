## 1. 실습 코드 및 단계별 해설

### 1.1 sys 모듈을 활용한 실행 환경 제어

```python
# sys 실행 관련 제어
import sys

print(sys.argv)  # 명령행 인수(Command line arguments) 리스트
print(sys.path)  # 파이썬 모듈 검색 경로 리스트

print('start')
sys.exit()       # 프로그램 즉시 정상 종료 (SystemExit 예외 발생)
print('end')     # sys.exit() 이후의 코드는 실행되지 않음
```

- **설명**:
  - `sys.argv`: 터미널에서 스크립트를 실행할 때 전달된 인수를 리스트 형태로 보관합니다.  
    (예: `python session5.py arg1 arg2` 실행 시 `sys.argv`는 `['session5.py', 'arg1', 'arg2']`)
  - `sys.path`: `import` 문을 실행할 때 파이썬 인터프리터가 모듈과 패키지를 탐색하는 디렉터리 경로 목록(문자열 리스트)입니다. 런타임 중에 새 경로를 `sys.path.append(...)`하여 외부 모듈을 동적으로 가져올 수도 있습니다.
  - `sys.exit()`: 호출 즉시 내부적으로 `SystemExit` 예외를 발생시키며 프로세스를 안전하게 종료합니다. 이후의 라인은 인터프리터에 의해 실행되지 않습니다.

---

## 2. 주요 속성 및 메서드 요약

| 항목 | 타입 / 용도 | 상세 설명 |
| :--- | :--- | :--- |
| `sys.argv` | `list` (문자열 목록) | 스크립트 실행 시 콘솔에서 입력한 파일명 및 파라미터 값 수집 |
| `sys.path` | `list` (경로 목록) | 모듈 검색 디렉토리 경로 집합 (현재 디렉터리, 가상환경, 내장 라이브러리 등) |
| `sys.exit()` | 함수 (프로세스 종료) | 0은 정상 종료, 0이 아닌 정수/메시지는 비정상 종료 코드로 프로세스를 탈출 |
